## 4. СТРУКТУРА НА ДАННИТЕ (`STEPS` масив в index.html)

Приложението има **11 стъпки × 96 точки**. Формат:

```js
{
  id: "3.3",                         // "step.sub" — уникален
  title: "Малка теорема на Ферма",
  desc: "a^p ≡ a (mod p)",
  source: "OT_2010, ТЧ (Ал. Иванов)",
  pdf: "Материали_БГ/OT_2010",
  page: 4,
  problems_page: 5,
  solutions_page: undefined,
  tasks: [
    { 
      label: "ОИ 2016/10 кл, Зад 1", 
      pdf: "Задачи_Минали_Години/OLI-2-Областен кръг-2016-10 кл-probs",
      page: 1,
      difficulty: 3,
      requires_also: ["6.1"],
      prerequisite_review: "Преговори 5.1 преди"
    }
  ],
  bonus: [
    { label: "Engel Ch 4", pdf: "Материали_EN/book-1", page: 113 }
  ],
  explanation: "ФОРМУЛИРОВКА: ...\n\nКОГА: ...\n\nСВОЙСТВА: ...\n\nТРИК: ..."
}
```

### Правила за полетата

| Поле | Задължително | Формат | Бележка |
|---|---|---|---|
| `id` | ✅ | `"N.M"` | Не се променя никога |
| `title` | ✅ | БГ текст | Кратко |
| `desc` | ✅ | БГ текст | 1 изречение |
| `source` | ✅ | `"Сборник, Автор"` | |
| `pdf` | ✅ | Път без `.pdf` | |
| `page` | ✅ | int | PDF page |
| `problems_page` | ❌ | int | Ако е различна |
| `solutions_page` | ❌ | int | Ако има отделен раздел |
| `tasks` | ❌ | Масив | За Step 10 и тематични задачи |
| `bonus` | ❌ | Масив | Допълнителни ресурси |
| `explanation` | ✅ | Многоредов БГ | Секции: ФОРМУЛИРОВКА, КОГА, СВОЙСТВА, ТРИК |

### Нови полета в `tasks[]`:
| Поле | Бележка |
|---|---|
| `difficulty` | 1 (лесно) до 5 (много трудно) |
| `requires_also` | ID-та на други нужни точки |
| `prerequisite_review` | Какво да преговоря преди |
