# W1 — Показателни: заместване и range

**Какво учиш (8 подтеми):**

1. `t = 2^x, t > 0` — базово
2. `t = 2^(2x+1) = 2·(2^x)²` — разгъване
3. `t = 4^x = (2^x)²` — двойно показателно
4. `t = 8^x = (2^x)³` — тройно
5. `t = (1/2)^x = 1/t` — реципрочно
6. `t = 2^(x²−x), t ≥ 2^(−1/4)` — с ограничение
7. `t = 2^(x+1/x), t ∈ (0, 2^(−2)] ∪ [2², ∞)` — с разклонение
8. `t = √(2^x) = √t` — квадратен корен

**Защо точно това:** Показателни се среща на 47% от области Task 1. Всяко от тези 8 замествания се е появявало в реален изпит (или вариация) поне веднъж. Пропуснеш ли едно, губиш цяла задача.

**Сигнали за разпознаване:**
- Видиш ли `a^x` в условието → това е показателно
- Ако степента е `2x` или `x²` или `x+1/x` → по-трудно заместване
- Ако имаш `4^x` до `2^x` → винаги `t = 2^x, 4^x = t²`

**Задачи:**

| Ден | Задача | Какво да внимаваш |
|---|---|---|
| Пон | 2020-11-1 | Basic `t = 2^x`. Провери D, продукт, сума. |
| Вто | 2021-11-1 | Същата техника, различна формулировка. |
| Сря | 2014-11-1 (първи опит) | `2t² − (a+8)t + a²+4 = 0`. Пълен case analysis. |
| Чет | Вариант с `4^x` | AI-generate. Проверка: `4^x = (2^x)²`. |
| Пет | Вариант с `2^(x²−x)` (2023-11-1) | Range: `x²−x ≥ −1/4`. |
| Съб | **Mini-mock (60 мин):** 2020-11-1 + 2023-11-1, timed | Пълни решения на хартия. |
| Нед | Analysis на mini-mock + spaced review на всички замествания | Напиши списък с range за всяко. |

**Mastery (неделя):**
- Виждаш показателно → 30 сек → заместване
- Познаваш range за всяко от 8-те замествания
- Решил 5/5 задачи с пълно решение, ≤40 мин всяка

**Edge cases, които проверяваш винаги:**
- `a = 0` (когато параметърът е в квадратното)
- `base = 1` (тривиално уравнение)
- `x = 0` дава ли `t = 1`?
- Отрицателни стойности на t (невалидни)

**Ако заседнеш:**
- Не разбираш заместването → върни се на article, раздел „8 замествания"
- Не разбираш range → генерирай 3 примера, където range е различен
- Не можеш да напишеш пълно решение → пренапиши article-а на ръка, стъпка по стъпка

**Ако свършиш рано:**
- Добави variant с `8^x`
- Добави mixed (показателно + параметър с тригонометрично в степента, ако имаш време)

**Article теми (генерират се):**
1. Защо показателни е #1 на областен
2. 8-те замествания (всяко с пример)
3. Range анализ за всяко
4. Защо range е толкова важен
5. 3 worked примера (basic, medium, mixed)

# W2 — Показателни с параметър: анализ на корени

**Какво учиш (6 подтеми):**

1. Заместване → квадратно в t
2. `D = b² − 4ac ≥ 0` — кога има реални t
3. Продукт `c/a`: положителен (двата корена с еднакъв знак) или отрицателен (различни знаци)
4. Сума `−b/a`: положителна (двата положителни) или отрицателна (двата отрицателни)
5. **Брой x решения = брой положителни t решения** (ключово!)
6. Пълен case analysis (0, 1, 2 решения)

**Защо точно това:** Това е „техниката" на показателни с параметър. Заместването (W1) е лесната част. Анализът (W2) е там, където губят точки всички. Ако не напишеш всички случаи (a=0, D=0, sum<0, t=0), губиш 2-3 точки от Task 1.

**Сигнали за разпознаване:**
- Показателно с параметър → след заместване виждаш квадратно `at² + bt + c = 0`
- Пита „за кои стойности на a има точно 1 / поне 1 / 2 решения" → анализ на корени
- Пита „за кои стойности на a няма решение" → отрицателния анализ

**Задачи:**

| Ден | Задача | Какво да внимаваш |
|---|---|---|
| Пон | 2014-11-1 (втори опит) | Пълен case: D<0, D=0, продукт<0, продукт>0 |
| Вто | 2014-11-1 (трети опит) | Напиши пълно решение без решенията. Провери със снимка. |
| Сря | Вариант: D=0 като критичен случай | AI-generate. |
| Чет | Вариант: a=0 като критичен случай | AI-generate. |
| Пет | Вариант: t=0 като edge case | AI-generate. |
| Съб | **Mini-mock (60 мин):** 2014-11-1 + 1 variant, timed | Пълни решения. |
| Нед | Analysis + спиши framework-а на случаите на карта | Напиши го на ръка 3 пъти. |

**Mastery:**
- Пишеш framework-а за анализ в ≤5 мин
- Решил 5/5 задачи с всички случаи покрити
- Не си пропуснал нито един edge case

**Edge cases:**
- `a = 0`: квадратното става линейно
- `D = 0`: един двоен корен (но трябва да е положителен)
- `t = 0`: невалиден, но трябва да се провери
- `сума < 0`: и двата корена отрицателни → няма x решение
- `сума = 0`: единият корен е отрицателен на другия

**Article теми:**
1. Пълен case analysis framework
2. Vieta + D + product + sum (как се комбинират)
3. 5 worked примера (от basic до mixed)
4. Чести грешки: пропуснат `a=0`, объркан знак, забравен D≥0
5. Speed — как да напишеш framework-а за 5 мин
