## 4. Конкретен седмичен режим (1–2 часа на ден)

### През Фаза 1–2 (основна + второстепенна)

| Ден | Дейност |
|---|---|
| Понеделник | Основна тема – теория (30 мин) + 1 задача (30 мин) |
| Вторник | Основна тема – теория (30 мин) + 1 задача (30 мин) |
| Сряда | Основна тема – 2 задачи (1 час) |
| Четвъртък | Второстепенна тема – теория (30 мин) + 1 задача (30 мин) |
| Петък | Второстепенна тема – 2 задачи (1 час) |
| Събота | 3 задачи – смесени (2 часа) |
| Неделя | Почивка или леко четене |

**Общо:** ~6–7 часа седмично.

### През Фаза 3–4 (редуване)

| Ден | Дейност |
|---|---|
| Понеделник | Тема A – теория + 1 задача |
| Вторник | Тема B – теория + 1 задача |
| Сряда | Тема A – 2 задачи |
| Четвъртък | Тема B – 2 задачи |
| Петък | Преговор на седмицата |
| Събота | Симулация (3 задачи, 2 часа) |
| Неделя | Почивка |
