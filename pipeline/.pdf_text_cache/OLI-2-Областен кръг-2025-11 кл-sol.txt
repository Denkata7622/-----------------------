Задача 11.1. Да се намерят всички стойности на реалния параметър $k$, за които корените на уравнението $2x^3 - (k^2 + 6)x^2 + (k^2 + k + 4)x - k = 0$ са реални положителни числа и образуват геометрична прогресия.

Отговор. $k = 2$.

Решение. Вижда се, че $x = 1$ е корен и уравнението придобива вида $(x - 1)P(x) = 0$, където

$$P(x) = 2x^2 - (k^2 + 4)x + k.$$

От $P(1) = -k^2 + k - 2 < 0, \forall k \in \mathbb{R}$ следва, че $P(x)$ има два различни реални корени $x_1 < x_2$, за които $x_1 < 1 < x_2$.

Имаме $x_1 > 0 \iff P(0) > 0$ и значи $k > 0$. Тъй като $x_1, 1, x_2$ образуват геометрична прогресия (в този ред), получаваме $x_1x_2 = 1$ и от формулите на Виет следва: $k/2 = 1$, т.е. $k = 2$. Обратното, за $k = 2$, корените $x_1, x_2$ на $P(x) = 0$ са положителни и удовлетворяват $x_1x_2 = 1$, т.е. условието на задачата е изпълнено.

Оценяване. (7 точки) 2 т. наблюдението, че $x = 1$ е корен и свеждане до квадратно уравнение; 2 т. за доказване, че 1 е средният член на геометричната прогресия; 3 т. за довършване.

Задача 11.2. Даден е тригълник $ABC$. Окръжност $k$ минава през върха $C$, допира се до правата $AB$ в точка $A$, пресича отсечката $BC$ в точка $P$ и медианата $CM$ в точка $Q$. Правата $BQ$ пресича $k$ в точка $R$. Да се докаже, че $PR$ е успоредна на $AB$.

Решение. Имаме $MB^2 = MA^2 = MQ.MC$, откъдето

$$\frac{MB}{MQ} = \frac{MC}{MB}. \tag{1}$$

От това равенство получаваме, че $\triangle MBQ \sim \triangle MCB$. Следователно $\angle MBC = \angle MQB$, откъдето намираме:

$$\frac{\widehat{RC}}{2} = \angle RQC = \angle MQB = \angle MBC = \frac{\widehat{RC}}{2} + \frac{\widehat{RA}}{2} - \frac{\widehat{AP}}{2}. \tag{2}$$

От (2) следва $\widehat{RA} = \widehat{AP}$, т.е. $RP \parallel AB$.

Оценяване. (7 точки) 1 т. за (1); 3 т. за $\triangle MBQ \sim \triangle MCB$; 3 т. за довършване на решението.

Задача 11.3. Нека $n$ е нечетно естествено число и $a_1, a_2, \dots, a_n$ е произволна пермутация на числата $1, 2, \dots, n$. Да се намери най-голямата стойност на израза:

$$|a_1 - 1| + |a_2 - 2| + \dots + |a_n - n|.$$

Отговор. $\frac{n^2 - 1}{2}$.

Решение. Перви подход. Ще докажем, че

$$|a_1 - 1| + |a_2 - 2| + \dots + |a_n - n| \leq \frac{n^2 - 1}{2}.$$

Да означим с $S$ израза от условието на задачата. Тъй като $|a_i - i| = a_i - i$ или $|a_i - i| = -a_i + i$, то от всяко събираемо в $S$ след „разкриване“ на модула ще получим едно положително и едно отрицателно число. Освен това всяко $k, 1 \leq k \leq n$ след разкриване на модулите ще се среща два пъти в $S$. Следователно

$$S = \pm 1 \pm 1 \pm 2 \pm 2 \pm 3 \pm \dots \pm n \pm n,$$

като броят на плюсовете е равен на броя на минусите. Най-голямата стойност на $S$ се достига когато първите $n$ събираеми са със знак минус, а следващите $n$ – със знак плюс.

Тогава

Лесно се вижда, че за всяка пермутация, за която са изпълнени равенствата

$$\left\{ a _ { 1 } , a _ { 2 } , \ldots , a _ { \frac { n - 1 } { 2 } } \right\} = \left\{ \frac { n + 3 } { 2 } , \frac { n + 5 } { 2 } , \ldots , n \right\} , a _ { \frac { n + 1 } { 2 } } = \frac { n + 1 } { 2 }$$

$$\left\{ a _ { \frac { n + 3 } { 2 } } , \ldots a _ { n } \right\} = \left\{ 1 , 2 , \ldots \frac { n - 1 } { 2 } \right\}$$

е вярно равенството $S = \frac { n ^ { 2 } - 1 } { 2 }$.

Втори подход. За пермутацията $a _ { k } : = n - k + 1 , k = 1 , 2 , \ldots , n$ изразът има стойност $\frac { n ^ { 2 } - 1 } { 2 }$. Сега за произволна пермутация ще докажем неравенството

$$\left| a _ { 1 } - 1 \right| + \left| a _ { 2 } - 2 \right| + \cdots + \left| a _ { n } - n \right| \leq \frac { n ^ { 2 } - 1 } { 2 } .$$

Върху числовата ос да разгледаме точките $1 , 2 , \ldots , n$ и за всяко $i = 1 , 2 , \ldots , n$ да свържем със стрелка от $a _ { i }$ към $i$. Дължина на стрелката ще наричаме числото $\left| a _ { i } - i \right|$. Във всяка точка $1 \leq i \leq n$ влиза една стрелка и излиза една стрелка. Искаме да оценим сумата от дължините на стрелките. Да разгледаме интервала $[ i , i + 1 ] , 1 \leq i \leq n - 1$ и да видим колко стрелки го покриват. Отляво на този интервал има $i$ възможни върхове $( 1 , 2 , \ldots , i )$, които могат да са начало/край на покриваща го стрелка. От дясната му страна има $n - i$ такива $( i + 1 , i + 2 , \ldots , n )$. Всеки от тези върхове може да участва максимум в две стрелки – като начало и като край. Така максималният брой стрелки, които могат да покриват интервала $[ i , i + 1 ]$, е равен на $2 \cdot \min ( i , n - i )$. Ако си представим дължината на всяка стрелка като сума на единичните интервали, които тя покрива, от казаното следва, че сумата на дължините на стрелките е най-много:

$$\sum _ { i = 1 } ^ { n - 1 } 2 \cdot \min ( i , n - i ) = 4 \sum _ { i = 1 } ^ { ( n - 1 ) / 2 } i = \frac { ( n - 1 ) ( n + 1 ) } { 2 } .$$

Оценяване. (7 точки) Първи подход: 1 т. за наблюдението, че след разкриване на модулите всяко число от 1 до $n$ се среща два пъти; 2 т. за наблюдението, че след разкриване на модулите броят на плюсовете е равен на броя на минусите; 1 т. за наблюдението, че най-голямата стойност на $S$ се достига когато първите $n$ събираеми са със знак минус, а следващите $n$ – със знак плюс; 1 т. за пресмятане на най-голямата стойност на $S$; 2 т. за пример на равенство.

Втори подход: 1 т. за наредба на числата върху числовата ос и интерпретация на сумата като сума от разстояния в пермутацията; 1 т. за наблюдението, че всеки интервал $[ i , i + 1 ]$ може да се покрие от стрелки с $i$ възможности от едната страна и $n - i$ възможности за другата; 2 т. за наблюдението, че всеки връх влиза в най-много 2 стрелки с извода, че всеки интервал се покрива от най-много $2 \min ( i , n - i )$ стрелки; 1 т. за пресмятането; 2 т. за пример.

Задача 11.4. Да се докаже, че за всяко естествено число $n$ съществува просто число $p < 2 ^ { 2 ^ { n } }$, за което $2 ^ { n }$ дели $p - 1$.

Решение. Имаме $2 ^ { 2 ^ { n } - 1 } = \left( 2 ^ { 2 ^ { n - 1 } - 1 } \right) \left( 2 ^ { 2 ^ { n - 1 } + 1 } \right)$. Нека $p$ е прост делител на $2 ^ { 2 ^ { n - 1 } + 1 }$. Ясно е, че $p \mid 2 ^ { 2 ^ { n } - 1 }$, но $p \nmid 2 ^ { 2 ^ { n - 1 } - 1 }$. Ще докажем, че $2 ^ { n }$ дели $p - 1$. Нека $k$ е показателя на 2 по модул $p$, т.е. $k$ е най-малкото естествено число, за което $p \mid 2 ^ { k } - 1$. От казаното следва $k \mid 2 ^ { n }$ и $k \nmid 2 ^ { n - 1 }$, което дава $k = 2 ^ { n }$. От друга страна, от малката теорема на Ферма получаваме: $2 ^ { p - 1 } \equiv 1 \pmod p$ и значи $k \mid p - 1$, т.е. $2 ^ { n } \mid p - 1$.

Оценяване. (7 точки) 2 т. за досещането да вземем за $p$ един прост делител на $2 ^ { 2 ^ { n - 1 } + 1 }$; 2 т. за разглеждането на показателя на 2 по модул $p$; 3 т. за довършване.
