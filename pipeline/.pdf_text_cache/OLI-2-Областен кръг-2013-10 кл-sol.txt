Задача 10.1. Да се намерят стойностите на реалния параметър $a$, за които уравне-нието

$$x^3 + ax^2 - (1 - a)^2 = 0$$

има три различни реални корена $x_1, x_2, x_3$, изпълняващи неравенството

$$\frac{x_1}{x_2 x_3} + \frac{x_2}{x_3 x_1} + \frac{x_3}{x_1 x_2} > \frac{3}{2}.$$

Решение. Имаме

$$x^3 + ax^2 - (1 - a)^2 = (x - (1 - a))(x^2 + x + (1 - a)) = 0.$$

Ако $D$ е дискриминантата на квадратния тричлен, то от $D > 0$ получаваме $a > 3/4$. Освен това $1 - a$ не трябва да е корен на квадратния тричлен, откъдето $a \neq 1, 3$. Използвайки формулите на Виет даденото по условие, получаваме

$$\frac{x_1}{x_2 x_3} + \frac{x_2}{x_3 x_1} + \frac{x_3}{x_1 x_2} = \frac{x_1^2 + x_2^2 + x_3^2}{x_1 x_2 x_3} = \frac{a^2}{(1 - a)^2} > \frac{3}{2},$$

което е изпълнено точно тогава, когато $a \in (3 - \sqrt{6}, 3 + \sqrt{6})$. Така окончателно

$$a \in \left(\frac{3}{4}, 1\right) \cup (1, 3) \cup (3, 3 + \sqrt{6}).$$

Оценяване: 1 т. за намиране на корена $x = 1 - a$; 1 т. за $a > 3/4$; 1 т. за $a \neq 1, 3$; 2 т. за свеждане на условието до квадратно неравенство за $a$; 1 т. за $a \in (3 - \sqrt{6}, 3 + \sqrt{6})$; 1 т. за окончателния отговор.

Задача 10.3. Да се намерят всички естествени числа $n$, за които

$$2^{n+1} \text{ дели } 7^{n!} - 3^{n!}.$$

($C$ $n!$ се означава произведението на естествените числа от 1 до $n$.)

Решение. Нека $n! = 2^k.m$, където $m$ е нечетно, а $k$ е цяло неотрицателно число. Тогава

$$7^{n!} - 3^{n!} = (7^m)^{2^k} - (3^m)^{2^k} = (7^m - 3^m)(7^m + 3^m)(7^{2m} + 3^{2m}) \dots (7^{2^{k-1}m} + 3^{2^{k-1}m}).$$

Тъй като $7^m + 3^m \equiv 7^{2m} + 3^{2m} \equiv \dots 7^{2^{k-1}m} + 3^{2^{k-1}m} \equiv 2 \pmod 4$ и $7^m - 3^m \equiv 4 \pmod 8$, то $2^{k+2} \mid (7^{n!} - 3^{n!})$, но $2^{k+3} \not\mid (7^{n!} - 3^{n!})$ и следователно $n + 1 \leqq k + 2$, т.е. $k \geqq n - 1$.

**Задача 10.4.** Нека $A ( n , k )$ е броят на $k$-орките $( a _ { 1 } , \ldots , a _ { k } )$ от цели числа, за които е изпълнено

$$\begin{array} { r c l } { a _ { 1 } + \ldots + a _ { k - 1 } } & { \leq } & { n , } \\ { a _ { 1 } + \ldots + a _ { k - 1 } + a _ { k } } & { > } & { n , } \\ { 1 \leq a _ { i } \leq n , } & { } & { i = 1 \ldots , k . } \end{array}$$

За кое $k$ стойността на $A ( 1 2 , k )$ е максимална?

**Решение.** Най-напред да пресметнем броя на $k$-орките $( a _ { 1 } , \ldots , a _ { k } )$ от цели числа $1 \leq a _ { i } \leq n$, за които $a _ { 1 } + \ldots + a _ { k } \leq n$. Очевидно тази сума може да взема сойностите $k , k + 1 , \ldots , n$ и следователно броят на тези $k$-орки е

$$\left( \begin{array} { l } { k - 1 } \\ { k - 1 } \end{array} \right) + \left( \begin{array} { l } { k } \\ { k - 1 } \end{array} \right) + \ldots + \left( \begin{array} { l } { n - 1 } \\ { k - 1 } \end{array} \right) = \left( \begin{array} { l } { n } \\ { k } \end{array} \right) .$$

Оттук получаваме, че броят на $k$-орките $( a _ { 1 } , \ldots , a _ { k } )$, за които $a _ { 1 } + \ldots + a _ { k - 1 } \leq n$, $a _ { 1 } + \ldots + a _ { k - 1 } + a _ { k } > n$, $1 \leq a _ { i } \leq n$ е

$$A ( n , k ) = n { \binom { n } { k - 1 } } - { \binom { n } { k } } = { \binom { n } { k } } \left( { \frac { n k } { n - k + 1 } } - 1 \right) .$$

Остава да определим, за кое $k$

$$A ( 1 2 , k ) = { \binom { 1 2 } { k } } \left( { \frac { 1 2 k } { 1 3 - k } } - 1 \right)$$

е максимално. Тъй като за $1 \leq k \leq 6$ и двата множителя растат, то е максимумът се достига за $6 \leq k \leq 1 2$. Имаме

$$\frac { A ( 1 2 , k + 1 ) } { A ( 1 2 , k ) } = \frac { k ( 1 3 - k ) } { k ^ { 2 } - 1 } .$$

Това отношение е по-голямо от 1 за $k = 6$ и по-малко от 1 за $k = 7 , \ldots , 1 2$. Следователно търсеният максимум се достига за $k = 7$.

**Оценяване:** 4 т. за извеждане на формула за $A ( n , k )$; 3 т. за намиране на стойността на $k$, за която $A ( 1 2 , k )$ е максимално.
