## Math errors
- `$s_a = \frac{2bc\cos A}{b+c}$` — Не е формулата за симетрала. При равностранен триъгълник дава a/2 вместо (√3/2)a. → $s_a = \frac{bc}{b^2+c^2}\sqrt{2b^2+2c^2-a^2}$
- `$h_c = c$ (прав триъгълник, C=90°)` — Височината от правия ъгъл към хипотенузата не е хипотенузата. При a=5, b=12: h_c = 60/13 ≈ 4.62, не 13. → $h_c = \frac{ab}{c}$
- `$m_a \approx 9.22$ (A(0,0), B(8,0), C(0,6))` — M = (4,3), AM = √(16+9) = 5. → $m_a = 5$
- `$b \approx 9.73$, $h_b \approx 8.73$ (Пример 2)` — b² = 244 − 120√2 ≈ 74.3 → b ≈ 8.62; h_b = 2·30√2/8.62 ≈ 9.84. → $b \approx 8.62$, $h_b \approx 9.84$
- `$m_a = l_a = s_a = \frac{b\sqrt{2}}{2}$ (равнобедрен)` — ½√(4b²−a²) = b√2/2 само при a=0. → $m_a = \sqrt{b^2 - a^2/4}$
- `$\theta_{MGL}+\theta_{GLK} \approx 23^\circ$ → 'точно 30°'` — Закръгляване не може да създаде 7° разлика. Сметките опровергават твърдението на задачата. → Задачата е некоректна или решението е грешно — regenerate
- `$\cos B = \frac{61}{91}$ (Пример 6, a=13, b=14, c=11)` — Правилно: cos B = (a²+c²−b²)/(2ac) = (169+121−196)/286 = 47/143. → $\cos B = \frac{47}{143}$
