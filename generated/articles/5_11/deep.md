# Ирационални уравнения и неравенства с параметър

## 1. Защо е важно

Ирационалните уравнения и неравенства с параметър са честа тема в олимпиадите и състезанията по математика. Те изискват задълбочено разбиране на допустимите стойности, повдигане на квадрат и анализ на параметрите. В областния кръг за 11 клас през 2009 г. (зад. 1) се пада задача с уравнение от вида √(x² + x + 3) = x − a, където трябва да се анализира параметърът a. През 2024 г. (зад. 1) има задача с произведение на изрази, включващи радикали. През 2004 г. (зад. 1) се среща задача за намиране на параметър, при който уравнението има точно две решения. Тези задачи тестват уменията ти за:
- Анализ на допустимите стойности при наличие на параметър
- Преработка на уравнението след повдигане на квадрат
- Проверка на решенията и изключване на страничните корени
- Класификация според стойностите на параметъра

## 2. Какво ще научиш

След тази статия ще можеш:
1. Да определяш допустимите стойности за ирационални уравнения и неравенства с параметър
2. Да прилагаш повдигане на квадрат и да анализираш получените уравнения
3. Да проверяваш решенията и да изключваш страничните корени
4. Да различиш кога задачата изисква анализ на параметър и кога е чисто алгебрична

## 3. Теория

### 3.1 Интуиция — пример преди формула

Разгледай задача от областния кръг за 11 клас през 2009 г.: Да се реши уравнението √(x² + x + 3) = x − a, където a е реален параметър. Първо, забелязваш, че изразът под корена x² + x + 3 е винаги положителен, тъй като дискриминантата му е 1 - 12 = -11 < 0. Следователно, допустимите стойности за x са всички реални числа. Сега обърни внимание на дясната страна: x − a. Корен квадратен е винаги неотрицателен, така че дясната страна трябва да е ≥ 0. Това означава, че x ≥ a. Ако x < a, уравнението няма решение. Когато x ≥ a, повдигаш двете страни на квадрат:

√(x² + x + 3) = x − a → x² + x + 3 = (x − a)²

Разкриваш скобите отдясно: x² + x + 3 = x² − 2ax + a². След опростяване получаваш: x + 3 = −2ax + a². Прехвърляш всички членове вляво: (1 + 2a)x − (a² − 3) = 0. Това е линейно уравнение спрямо x. При a ≠ −1/2, решението е x = (a² − 3)/(1 + 2a). Но не забравяй, че трябва да провериш дали това решение удовлетворява първоначалното уравнение и условието x ≥ a. Например, при a = -1, x = (1 - 3)/(1 - 2) = (-2)/(-1) = 2. Проверяваме: √(4 - 2 + 3) = √5 ≈ 2.236, а x - a = 2 - (-1) = 3. 2.236 ≠ 3, значи не е решение. Затова винаги трябва да заместваш обратно. Това е интуицията: преди да прилагаш механично повдигане на квадрат, винаги анализирай допустимите стойности и условието, и проверявай решенията.

### 3.2 Формално определение

Ирационално уравнение с параметър е уравнение, съдържащо радикал (корен) и параметър, например √f(x, a) = g(x, a). За да го решиш, трябва:
1. Да намериш допустимите стойности: f(x, a) ≥ 0 и g(x, a) ≥ 0 (ако радикалът е квадратен).
2. Да повдигнеш двете страни на квадрат, за да елиминираш корена.
3. Да решиш полученото уравнение спрямо x.
4. Да провериш кои от намерените решения удовлетворяват първоначалното уравнение и неравенствата от стъпка 1.
5. Да анализираш случаите, когато параметърът води до специални ситуации (например когато коефициентът пред x се нулира).

### 3.3 Теореми с доказателства

**Теорема 1:** При повдигане на квадрат на ирационално уравнение може да се получат странични корени. Всички решения на новото уравнение трябва да се проверят в първоначалното.

*Доказателство:* Нека имаме √A = B. Повдигаме на квадрат: A = B². Но B² = A може да има решения, за които B < 0, докато първоначалното уравнение изисква B ≥ 0. Следователно, решенията на A = B², за които B < 0, не са решения на √A = B. Например, √(x) = −1. Повдигаме на квадрат: x = 1. Но при x = 1, √1 = 1 ≠ −1. Значи x = 1 е страничен корен.

**Теорема 2:** Ако √A = B и B ≥ 0, то повдигането на квадрат е еквивалентна операция, т.е. няма загуба на решения.

*Доказателство:* По дефиниция, √A ≥ 0. Ако √A = B и B ≥ 0, то B е неотрицателно число. Тогава A = B² е вярно. Обратно, ако A = B² и B ≥ 0, то √A = |B| = B, тъй като B ≥ 0. Следователно, двете уравнения са еквивалентни при условие B ≥ 0.

### 3.4 Връзка с училищната математика

В училище си учил за ирационални уравнения без параметри, например √(2x + 3) = x. Там проверката на решенията е лесна, защото няма параметри. С параметри, задължително трябва да класифицираш според стойностите им. Например, в уравнението √(x² + x + 3) = x − a, при a = −1/2, уравнението след повдигане на квадрат става 0·x = (−1/2)² − 3, т.е. 0 = −11/4, което е невъзможно. Следователно, за a = −1/2 няма решение. Това е връзката с линейните уравнения, които си учил в по-ниски класове — когато коефициентът пред x е нула, имаш специален случай.

### 3.5 Множество гледни точки

Можеш да подходиш към ирационалните уравнения с параметър по два начина:

**Алгебричен подход:** Това е стандартният начин — повдигане на квадрат и проверка на решенията. Например в задачата от 2009 г., след повдигане получаваш линейно уравнение, което решаваш спрямо x, след което проверяваш условието x ≥ a и заместваш обратно в оригиналното.

**Графичен подход:** Можеш да разглеждаш лявата и дясната страна като функции и да търсиш тяхното пресичане. За √(x² + x + 3) = x − a, лявата страна е винаги положителна парабола, а дясната е права с наклон 1 и пресичаща оста y в −a. Броят на решенията зависи от това къде правата пресича параболата. Този подход е полезен за бърза визуализация, но не е толкова точен за получаване на точни стойности.

### 3.6 Edge cases

Специални случаи, които трябва да проверяваш винаги:

1. **Когато изразът под корена става отрицателен:** В някои задачи това зависи от параметъра. Например, ако имаш √(ax + b), трябва ax + b ≥ 0. При a > 0, x ≥ −b/a; при a < 0, x ≤ −b/a; при a = 0, b ≥ 0 иначе няма решение.

2. **Когато дясната страна става отрицателна:** Корен квадратен е ≥ 0, така че ако дясната страна е отрицателна, няма решение.

3. **Когато след повдигане на квадрат коефициентът пред x се нулира:** Както в задачата от 2009 г. при a = −1/2. Тогава получаваш уравнение без x (константно) и трябва да провериш дали е вярно.

4. **Когато полученото уравнение след повдигане е идентично вярно или невярно:** Например, ако след повдигане получиш 0 = 0, това означава, че всяко x от допустимите стойности е решение. Ако получиш 0 = c (c ≠ 0), няма решение.

## 4. Примери с решения

### 4.1 Easy examples (3)

**Пример 1:** [OLI-2-Областен кръг-2009-11 кл · 2009-11 · Зад. 1]
Условие: Да се реши уравнението √(x² + x + 3) = x − a, където a е реален параметър.

**Как мисля:** Виждам квадратен корен и параметър. Първо, проверявам допустимите стойности. Изразът под корена x² + x + 3 има дискриминанта 1 − 12 = −11 < 0, така че е винаги положителен. Значи x е всяко реално число. Сега, коренът е неотрицателен, така че дясната страна трябва да е ≥ 0: x ≥ a. Ако x < a, няма решение. Повдигам на квадрат двете страни:

x² + x + 3 = (x − a)²
x² + x + 3 = x² − 2ax + a²
x + 3 = −2ax + a²
(1 + 2a)x = a² − 3

При a ≠ −1/2, решението е x = (a² − 3)/(1 + 2a). Трябва да проверим дали това решение удовлетворява първоначалното уравнение и x ≥ a. Замествам x в оригиналното уравнение. Например при a = -1, x = (1 - 3)/(1 - 2) = (-2)/(-1) = 2. Лява страна: √(4 - 2 + 3) = √5 ≈ 2.236. Дясна страна: 2 - (-1) = 3. 2.236 ≠ 3, значи не е решение. Затова винаги трябва да заместваш обратно. В реалното решение се налага допълнително условие: x = (a² − 3)/(1 + 2a) ≥ a. След заместване:

(a² − 3)/(1 + 2a) ≥ a
(a² − 3 - a(1 + 2a))/(1 + 2a) ≥ 0
(a² − 3 - a - 2a²)/(1 + 2a) ≥ 0
(-a² - a - 3)/(1 + 2a) ≥ 0

Умножавам числителя и знаменателя по -1 (обръщам знака на неравенството):

(a² + a + 3)/(1 + 2a) ≤ 0

Числителят a² + a + 3 > 0 за всички a (дискриминанта 1 - 12 = -11 < 0). Значи дробта е неположителна само когато знаменателят е отрицателен: 1 + 2a < 0 → a < -1/2.

При a = -1/2, уравнението става: (1 + 2*(-1/2))x = (-1/2)^2 - 3 → 0*x = 1/4 - 12/4 = -11/4 → невярно. Значи няма решение.

**Решение:** При a ≥ -1/2 няма решение. При a < -1/2, решението е x = (a² - 3)/(1 + 2a), но само ако удовлетворява оригиналното уравнение. В този случай, защото сме наложили x ≥ a и повдигането на квадрат е било при това условие, то е решение. Но винаги трябва да се прави проверка. Например при a = -2, x = (4 - 3)/(1 - 4) = 1/(-3) = -1/3. Проверка: лява страна √(1/9 - 1/3 + 3) = √(1/9 - 3/9 + 27/9) = √(25/9) = 5/3. Дясна страна: -1/3 - (-2) = 5/3. Равни, значи е решение.

**Забележи:** Винаги проверявай случая, когато коефициентът пред x се нулира (a = -1/2 тук) и прави проверка на решението.

**Пример 2:** Типичен пример (не от минала олимпиада)
Условие: Да се реши √(x + 2) = x + a за реалния параметър a.

**Как мисля:** Първо, допустими стойности: x + 2 ≥ 0 → x ≥ -2. И дясната страна x + a ≥ 0 → x ≥ -a. Повдигам на квадрат:

x + 2 = (x + a)²
x + 2 = x² + 2ax + a²
x² + 2ax + a² - x - 2 = 0
x² + (2a - 1)x + (a² - 2) = 0

Дискриминанта D = (2a - 1)^2 - 4*1*(a² - 2) = 4a² - 4a + 1 - 4a² + 8 = -4a + 9.

При D < 0, т.е. a > 9/4, няма реални решения. При D ≥ 0, a ≤ 9/4, решенията са x = [-(2a-1) ± √D]/2. Трябва да удовлетворяват x ≥ -2 и x ≥ -a. Също, трябва да проверим дали са ≥ -a (защото повдигането на квадрат изисква x + a ≥ 0).

**Решение:** Това е по-сложно и ще го оставим за упражнение. Основното е да видиш структурата.

**Пример 3:** Типичен пример (не от минала олимпиада)
Условие: Да се реши уравнението √(x - a) = a - x.

**Как мисля:** Първо, допустими стойности: x - a ≥ 0 → x ≥ a и a - x ≥ 0 → x ≤ a. Значи x = a. Замествам: √(a - a) = a - a → 0 = 0, винаги вярно. 

**Решение:** При всички a, решението е x = a.

### 4.2 Medium examples (4)

**Пример 4:** [OLI-2-Областен кръг-2004-10 кл · 2004-10 · Зад. 1]
Условие: Да се намерят стойностите на реалния параметър a, за които уравнението √((4a² − 4a − 1)x² − 2ax + 1) = 1 − ax − x² има точно две решения.

**Как мисля:** Виждам радикал и квадратна функция отдясно. Първо, дясната страна трябва да е ≥ 0: 1 − ax − x² ≥ 0. Повдигам на квадрат:

(4a² − 4a − 1)x² − 2ax + 1 = (1 − ax − x²)²

Разкриваме дясната страна: (1 - ax - x²)² = 1 - 2ax - 2x² + a²x² + 2ax³ + x⁴? Не, по-добре да умножим внимателно. В реалното решение директно са получили:

x²(x² + 2ax - 3a² + 4a - 1) = 0

За да стигнем до това, пренасяме всичко вляво:

(4a² - 4a - 1)x² - 2ax + 1 - (1 - ax - x²)² = 0

Това е сложно, но може да се опрости. Вместо това, следваме реалното решение: след повдигане на квадрат се получава

x²(x² + 2ax - 3a² + 4a - 1) = 0

Значи x = 0 или x² + 2ax - 3a² + 4a - 1 = 0.

**Решение:** От реалното решение: x₁ = 0, x₂ = 1 - 3a, x₃ = a - 1.

x₁ = 0 е решение за всяко a, но трябва да е в допустимите стойности. При x = 0, дясната страна е 1 ≥ 0, значи винаги е решение.

x₂ = 1 - 3a е решение, когато дясната страна ≥ 0: 1 - a(1 - 3a) - (1 - 3a)² ≥ 0. Изчисляваме:

1 - a + 3a² - (1 - 6a + 9a²) = 1 - a + 3a² - 1 + 6a - 9a² = -6a² + 5a ≥ 0
5a - 6a² ≥ 0
a(5 - 6a) ≥ 0 → a ∈ [0, 5/6]

Аналогично за x₃ = a - 1: 1 - a(a-1) - (a-1)² ≥ 0
1 - a² + a - (a² - 2a + 1) = 1 - a² + a - a² + 2a - 1 = -2a² + 3a ≥ 0
a(3 - 2a) ≥ 0 → a ∈ [0, 3/2]

Сега, за да има точно две решения, трябва да разгледаме кога имаме повтарящи се корени или кога някои не са валидни.

Случай 1: Някои корени са равни. Това става когато x₁ = x₂, x₁ = x₃ или x₂ = x₃.
- x₁ = x₂: 0 = 1 - 3a → a = 1/3
- x₁ = x₃: 0 = a - 1 → a = 1
- x₂ = x₃: 1 - 3a = a - 1 → 2 = 4a → a = 1/2

При a = 1/3: x₁ = 0, x₂ = 1 - 1 = 0, значи един корен x=0. Но x₃ = 1/3 - 1 = -2/3. Проверяваме дали x₃ е решение: a=1/3 ∈ [0, 3/2], значи е решение. Значи имаме две решения: x=0 и x=-2/3.

При a=1/2: x₁=0, x₂=1-1.5=-0.5, x₃=0.5-1=-0.5. Значи корените са x=0 и x=-0.5 (два пъти, но това е едно решение). Значи две решения: x=0 и x=-0.5.

При a=1: x₁=0, x₂=1-3=-2, x₃=1-1=0. Значи корените са x=0 (два пъти) и x=-2. Проверяваме за x=-2: a=1 ∈ [0, 5/6]? 1 > 5/6, значи не е в интервала. Значи само x=0 е решение. Следователно при a=1 има само едно решение.

Случай 2: Всички корени са различни. Тогава трябва да имаме точно три корена, но само два от тях да са валидни. Това става, когато само един от трите не е валиден. Например, ако x₂ не е валиден, но x₁ и x₃ са, тогава имаме две решения. x₂ не е валиден, когато a ∉ [0,5/6]. x₃ не е валиден, когато a ∉ [0,3/2].

Ако a > 5/6 и a ≤ 3/2, и a ≠ 1, тогава x₂ не е валиден, но x₁ и x₃ са валидни. Значи две решения. При a=1, както видяхме, има само едно решение.

**Решение:** a = 1/3, a = 1/2 и a ∈ (5/6, 3/2] \ {1}.

**Забележи:** Трябва много внимателно да се проверяват случаите на равни корени и дали те са валидни решения.

За първото: (x + √2)(√5 − x) = 3
Разкривам скобите: x√5 − x² + √10 − x√2 = 3
−x² + (√5 − √2)x + √10 − 3 = 0
Умножавам по −1: x² − (√5 − √2)x − √10 + 3 = 0

Дискриминанта D = (√5 − √2)^2 − 4*1*(−√10 + 3) = (5 − 2√10 + 2) + 4√10 − 12 = 7 − 2√10 + 4√10 − 12 = −5 + 2√10

За второто: (x + √2)(√5 − x) = 4
Аналогично: −x² + (√5 − √2)x + √10 − 4 = 0

**Пример 6:** Типичен пример (не от минала олимпиада)
Условие: Да се реши уравнението √(x + a) + √(x - a) = 2 за реалния параметър a.

**Как мисля:** Допустими стойности: x ≥ |a| (защото x + a ≥ 0 и x - a ≥ 0). Повдигам на квадрат двете страни:

(√(x + a) + √(x - a))² = 4
(x + a) + 2√((x + a)(x - a)) + (x - a) = 4
2x + 2√(x² - a²) = 4
x + √(x² - a²) = 2

Изолирам корена: √(x² - a²) = 2 - x

Повдигам на квадрат: x² - a² = (2 - x)²
x² - a² = 4 - 4x + x²
- a² = 4 - 4x
4x = 4 + a²
x = 1 + a²/4

Проверка на допустимите стойности: x ≥ |a| и 2 - x ≥ 0 → x ≤ 2. Значи 1 + a²/4 ≥ |a| и 1 + a²/4 ≤ 2. Второто е винаги изпълнено, защото a²/4 ≤ 1 → a² ≤ 4 → |a| ≤ 2. Първото: 1 + a²/4 ≥ |a|. Ако a ≥ 0, 1 + a²/4 ≥ a → a²/4 - a + 1 ≥ 0 → (a/2 - 1)^2 ≥ 0, винаги. Аналогично за a < 0. Също, x = 1 + a²/4 ≤ 2, така че 2 - x ≥ 0. Остава да проверим в оригиналното уравнение. Замествам: лявата страна √(1 + a²/4 + a) + √(1 + a²/4 - a) = √((1 + a/2)^2) + √((1 - a/2)^2) = |1 + a/2| + |1 - a/2|. При |a| ≤ 2, това е (1 + a/2) + (1 - a/2) = 2. Значи е решение.

**Решение:** За |a| ≤ 2, решението е x = 1 + a²/4.

**Пример 7:** [OLI-2-Областен кръг-2004-10 кл · 2004-10 · Зад. 1] (неравенство)
Условие: Да се реши неравенството √(x² − 1) + √(2x² − 3) + x√3 > 0.

**Как мисля:** Това е ирационално неравенство. Първо, намирам допустимите стойности:

x² − 1 ≥ 0 → |x| ≥ 1
2x² − 3 ≥ 0 → |x| ≥ √(3/2) = √6/2 ≈ 1.2247

Значи x ∈ (−∞, −√6/2] ∪ [√6/2, ∞).

Сега, в интервала [√6/2, ∞), всички членове са неотрицателни: √(x² − 1) ≥ 0, √(2x² − 3) ≥ 0, x√3 > 0. Значи сумата им е > 0 за всички x ≥ √6/2.

Остава интервалът (−∞, −√6/2]. Тук x < 0, така че x√3 < 0. Трябва да видя кога сумата е положителна. Прехвърлям x√3 отдясно:

√(x² − 1) + √(2x² − 3) > −x√3

Но дясната страна −x√3 > 0, тъй като x < 0. Повдигам на квадрат двете страни. Лявата страна е положителна, дясната също, така че мога да повдигам на квадрат. Обаче имам два корена отляво. За да го направя, полагам A = √(x² − 1), B = √(2x² − 3). Тогава (A + B)² > (−x√3)², т.е. A² + B² + 2AB > 3x².

A² = x² − 1, B² = 2x² − 3, така че:

(x² - 1) + (2x² - 3) + 2√((x² - 1)(2x² - 3)) > 3x²
3x² - 4 + 2√((x² - 1)(2x² - 3)) > 3x²
-4 + 2√((x² - 1)(2x² - 3)) > 0
2√((x² - 1)(2x² - 3)) > 4
√((x² - 1)(2x² - 3)) > 2

Повдигам на квадрат отново (и двете страни са неотрицателни):

(x² - 1)(2x² - 3) > 4
2x⁴ - 3x² - 2x² + 3 > 4  # (x²)(2x²) + (x²)(-3) + (-1)(2x²) + (-1)(-3) = 2x⁴ - 3x² - 2x² + 3
2x⁴ - 5x² + 3 - 4 > 0
2x⁴ - 5x² - 1 > 0

Полагам u = x². Уравнението е 2u² - 5u - 1 > 0. Дискриминанта D = 25 + 8 = 33. Корените u = [5 ± √33]/4.

Тъй като коефициентът пред u² е положителен, неравенството е изпълнено за u < [5 - √33]/4 или u > [5 + √33]/4. Но [5 - √33]/4 < 0 (√33≈5.744>5), а u = x² ≥ 0. Значи остава u > [5 + √33]/4 ≈ (5+5.744)/4 ≈ 10.744/4 ≈ 2.686.

Тоест x² > [5 + √33]/4. Тъй като x < 0, това значи x < -√([5 + √33]/4) = -√(5 + √33)/2.

Сега трябва да се съобразим с допустимите стойности: x ≤ -√6/2 ≈ -1.2247. И √([5 + √33]/4) ≈ √2.686 ≈ 1.638, така че -√([5 + √33]/4) ≈ -1.638. Тъй като -1.638 < -1.2247, то в интервала x ≤ -√6/2, неравенството е изпълнено за x < -√([5 + √33]/4).

**Решение:** x ∈ (−∞, −√((5 + √33)/4)) ∪ [√6/2, +∞).

**Забележи:** При x < 0, повдигането на квадрат е валидно, защото и двете страни са положителни.

**Пример 8:** [OLI-2-Областен кръг-2024-11 кл · 2024-11 · Зад. 1б]
Условие: Нека M и m са съответно най-големият и най-малкият сред реалните корени на даденото уравнение от част а). Намерете естествени числа p, q, r, s, за които уравнението y² + (√p − √q)y + r − √s = 0 има корени y₁ = 3M − m и y₂ = 3m − M.

**Как мисля:** От част а) знаем, че уравнението има два реални корена (решения на (x + √2)(√5 − x) = 3). Нека ги означим с m и M, като m < M. Формулите на Виет: m + M = √5 - √2, m·M = 3 - √10.

Корените на новото уравнение са y₁ = 3M − m, y₂ = 3m − M. Трябва да намерим сбора и произведението им.

Сбор: y₁ + y₂ = (3M - m) + (3m - M) = 2M + 2m = 2(m + M) = 2(√5 - √2)

Произведение: y₁·y₂ = (3M - m)(3m - M) = 9mM - 3M² - 3m² + mM = 10mM - 3(m² + M²)

m² + M² = (m + M)² - 2mM = (√5 - √2)² - 2(3 - √10) = (5 - 2√10 + 2) - 6 + 2√10 = 7 - 2√10 - 6 + 2√10 = 1

Значи произведение: 10(3 - √10) - 3*1 = 30 - 10√10 - 3 = 27 - 10√10

Търсим уравнението y² - (сбор)y + произведение = 0, т.е.

y² - 2(√5 - √2)y + (27 - 10√10) = 0

За да получим коефициентите в искания вид, сравняваме с y² + (√p − √q)y + (r − √s) = 0. Значи:

√p - √q = -2(√5 - √2) = -2√5 + 2√2

Това не е точно в търсената форма, но можем да го запишем като (2√2 - 2√5). За да получим √p - √q, трябва p и q да са такива, че 2√2 = √8, 2√5 = √20. Значи √p - √q = √8 - √20.

Свободният член r - √s = 27 - 10√10. Тук 10√10 = √(100 * 10) = √1000. Значи r - √s = 27 - √1000.

**Решение:** p=8, q=20, r=27, s=1000.

## 5. Как да разпознаеш

Сигнали, че задачата е за ирационални уравнения/неравенства с параметър:
1. Има радикал (корен) и параметър в уравнението или неравенството.
2. Често се изисква да се намерят стойностите на параметъра, за които уравнението има определен брой решения.
3. В условието има изрази като "за всяко a", "съществува a", "точно k решения".
4. След повдигане на квадрат се получава полиномно уравнение, което може да се анализира.

Контрапримери (когато не е):
- Ако няма радикал, а има параметър, това е обикновено алгебрично уравнение.
- Ако радикалът е само един и без параметър, но с модули или други елементи, може да е по-проста задача.

## 6. Чести грешки

1. **Забравяне на допустимите стойности:** Да не се провери кога изразът под корена е неотрицателен или кога дясната страна е неотрицателна.
   *Защо:* Учениците се фокусират върху повдигането на квадрат и забравят предварителните условия.
   *Как да избегнеш:* Винаги записвай ДМ преди да започнеш решението.

2. **Неправилно повдигане на квадрат:** Когато имаш сума от радикали, повдигането на квадрат изисква формула (a + b)² = a² + b² + 2ab.
   *Защо:* Учениците опитват да повдигнат всеки радикал поотделно.
   *Как да избегнеш:* Винаги използвай (A + B)² = A² + B² + 2AB.

3. **Проверка само на сметката, но не и на условието:** Да се намерят решенията на полученото уравнение, но да не се проверят спрямо първоначалните условия (например x ≥ a).
   *Защо:* Мисли се, че повдигането на квадрат е еквивалентно, но не е, ако не е спазено условието за неотрицателност.
   *Как да избегнеш:* Винаги замествай намерените решения в първоначалното уравнение.

4. **Игнориране на специални стойности на параметъра:** Когато коефициентът пред x се нулира (напр. a = −1/2 в пример 1).
   *Защо:* Учениците решават общия случай и забравят да проверят случаите, когато знаменателят е нула.
   *Как да избегнеш:* Винаги търси стойности на параметъра, при които коефициентите се нулират.

5. **Грешки при решаване на неравенства с параметър:** Обръщане на знака на неравенството без да се вземе предвид знакът на знаменателя.
   *Защо:* Забравя се, че при умножаване с отрицателно число, знакът на неравенството се обръща.
   *Как да избегнеш:* Винаги анализирай знака на изразите, с които умножаваш.

## 8. Самооценка (Quiz)

1. **Basic (дали знае какво е):** Какви са допустимите стойности за x в уравнението √(x + a) = x?  
   Отговор: x + a ≥ 0 и x ≥ 0 (защото коренът е ≥0).

2. **Edge case (знае ли кога НЕ работи):** При каква стойност на параметъра a уравнението √(x² + 1) = x − a няма решение?  
   Отговор: При a > 0, защото лявата страна е винаги ≥1, а дясната x - a < x ≤ √(x² + 1) само ако a=0, иначе √(x² + 1) > x - a за всички x.

3. **Discrimination (различава ли X от Y):** Кое от следните уравнения е ирационално с параметър?  
   а) √(x) = a  
   б) x² + a x + 1 = 0  
   в) |x − a| = 2  
   Отговор: а) е ирационално с параметър.

4. **Counterexample (може ли да намери грешното в решение):** В решението на √(x − 1) = a − x се получава x − 1 = (a − x)², след което се решава като квадратно. Каква е грешката?  
   Отговор: Не е проверено условието a − x ≥ 0.

5. **Transfer (може ли да приложи в нов контекст):** Как ще подходиш към неравенството √(x² + a) > x + 1?  
   Отговор: Първо, ДМ: x² + a ≥ 0. Ако a ≥ 0, ДМ е цялата права. Ако a < 0, |x| ≥ √(−a). После, ако x + 1 < 0, неравенството е изпълнено автоматично (лявата страна ≥0 > x+1). Ако x + 1 ≥ 0, повдигам на квадрат: x² + a > (x + 1)² → x² + a > x² + 2x + 1 → a > 2x + 1 → x < (a − 1)/2. Но трябва x ≥ -1. Така комбинирам случаите.
