## 1. Защо е важно
Формулите на Виет не са просто училищна теория — те са мощен инструмент в олимпиадните задачи. Виж как се използват в реални проблеми:

- В **OLI-2-Областен кръг-1995-11 кл, Зад. 1** (парабола без пресечни точки с абсцисната ос) те позволяват да се свърже геометрично условие (∠AOB=90°) с дискриминанта на квадратно уравнение. Без Виет, решението би било много по-сложно.
- В **OLI-2-Областен кръг-1997-10 кл, Зад. 1** (система от три квадратни уравнения с естествени корени) формулите за сума и произведение директно водят до ключовото наблюдение, че поне един корен трябва да е 1.
- В **OLI-2-Областен кръг-2000-10 кл, Зад. 1** (параметрично уравнение с показателна функция) полагането x=3^t свежда задачата до квадратно уравнение, където Виет помага да се анализира броят на корените в интервал.

Тези задачи илюстрират три различни приложения: геометрична интерпретация, комбинаторен анализ на корени и параметричен изследване. Без владеене на Виет, тези задачи стават нерешими за ограниченото време на изпит.

## 3. Теория
### 3.1 Интуиция — пример преди формула
Нека разгледаме конкретна задача: "Квадратното уравнение x² - 5x + 6 = 0 има корени 2 и 3. Намери сумата и произведението им." Лесно: 2+3=5, 2*3=6. Забележи, че 5 е противоположното на коефициента пред x, а 6 е свободният член. Сега да пробваме с друго: x² + 7x + 12 = 0 с корени -3 и -4. Сума: -3 + (-4) = -7 (противоположно на коефициента пред x). Произведение: (-3)*(-4)=12 (свободен член). Виждаш ли вече модела?

### 3.2 Формално определение
За общо квадратно уравнение ax² + bx + c = 0 с корени x₁ и x₂:
- **Сума на корените**: x₁ + x₂ = -b/a
- **Произведение на корените**: x₁x₂ = c/a

За кубично уравнение ax³ + bx² + cx + d = 0 с корени x₁, x₂, x₃:
- x₁ + x₂ + x₃ = -b/a
- x₁x₂ + x₂x₃ + x₃x₁ = c/a
- x₁x₂x₃ = -d/a

За уравнение от n-та степен: aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀ = 0 с корени x₁, x₂, ..., xₙ:
- Сума на всички корени: ∑xᵢ = -aₙ₋₁/aₙ
- Сума на произведенията по два: ∑xᵢxⱼ = aₙ₋₂/aₙ
- ...
- Произведение на всички корени: ∏xᵢ = (-1)ⁿ a₀/aₙ

### 3.3 Теореми с доказателства
**Теорема 1 (квадратно уравнение)**: Ако x₁, x₂ са корени на ax² + bx + c = 0, то x₁ + x₂ = -b/a и x₁x₂ = c/a.
*Доказателство*: Разлагаме на множители: a(x - x₁)(x - x₂) = 0. Разкриваме скобите: a[x² - (x₁+x₂)x + x₁x₂] = ax² - a(x₁+x₂)x + a x₁x₂. Сравняваме с оригиналното уравнение ax² + bx + c = 0. Коефициентите трябва да съвпадат:
- При x: -a(x₁+x₂) = b ⇒ x₁+x₂ = -b/a
- Свободен член: a x₁x₂ = c ⇒ x₁x₂ = c/a. ∎

**Теорема 2 (кубично уравнение)**: Ако x₁, x₂, x₃ са корени на ax³ + bx² + cx + d = 0, то x₁+x₂+x₃ = -b/a, x₁x₂ + x₂x₃ + x₃x₁ = c/a, x₁x₂x₃ = -d/a.
*Доказателство*: a(x - x₁)(x - x₂)(x - x₃) = 0. Разкриваме скобите стъпка по стъпка:
1. (x - x₁)(x - x₂) = x² - (x₁+x₂)x + x₁x₂
2. Умножаваме по (x - x₃): [x² - (x₁+x₂)x + x₁x₂](x - x₃) = x³ - x₃x² - (x₁+x₂)x² + (x₁+x₂)x₃x + x₁x₂x - x₁x₂x₃
Групираме: x³ - (x₁+x₂+x₃)x² + (x₁x₂ + x₁x₃ + x₂x₃)x - x₁x₂x₃
Умножаваме по a: ax³ - a(x₁+x₂+x₃)x² + a(x₁x₂ + x₁x₃ + x₂x₃)x - a x₁x₂x₃
Сравняваме с ax³ + bx² + cx + d:
- При x²: -a(x₁+x₂+x₃) = b ⇒ x₁+x₂+x₃ = -b/a
- При x: a(x₁x₂ + x₁x₃ + x₂x₃) = c ⇒ x₁x₂ + x₁x₃ + x₂x₃ = c/a
- Свободен член: -a x₁x₂x₃ = d ⇒ x₁x₂x₃ = -d/a. ∎

### 3.4 Връзка с училищната математика
В училище се учиш, че за квадратно уравнение ax² + bx + c = 0, дискриминантата D = b² - 4ac определя реалността на корените. Но формулите на Виет дават повече — те показват връзката между корените без дори да ги намираш. Например, ако знаеш, че сумата на корените е отрицателна, а произведението положително, то и двата корена са отрицателни (ако са реални). Това не можеш да получиш от дискриминантата.

### 3.5 Множество гледни точки
Можеш да мислиш за Виет алгебрично или геометрично:
- **Алгебрично**: Формулите са резултат от разкриване на скоби в разлагането на множители. Фокусът е върху коефициентите.
- **Геометрично**: За квадратно уравнение, корените са точки, където параболата пресича абсцисната ос. Сумата x₁+x₂ е абсцисата на върха с обратен знак, умножена по 2 (защото върхът е при x = -b/(2a) = (x₁+x₂)/2).

### 3.6 Edge cases
- **Когато a=0**: Уравнението вече не е квадратно. Формулите не важат! Винаги проверявай степента.
- **Когато D=0**: Имаме двоен корен x₁ = x₂ = -b/(2a). Сумата е 2*(-b/(2a)) = -b/a, произведение (b²/(4a²)) = c/a. Работи, но е специален случай.
- **Когато корените са комплексни**: Формулите важат (напр. за x² + 1 = 0: корени i и -i, сума 0 = -0/1, произведение -1 = 1/1? Грешка! Внимавай: x² + 0x + 1 = 0 ⇒ сума = -0/1 = 0, произведение = 1/1 = 1, а i*(-i) = -i² = -(-1) = 1. Да, работи.
- **Когато коефициентът е нула**: Напр. в x³ - 6x² + 0x + 8 = 0. Сумата на произведенията по два е 0/1 = 0. Това значи, че ако корените са a,b,c, то ab+bc+ca=0.

### 4.1 Easy examples (2-3)
**Пример 1 (типичен, не от минала олимпиада)**: Квадратното уравнение x² - 4x + 3 = 0 има корени x₁ и x₂. Намери x₁ + x₂ и x₁x₂ без да решаваш уравнението.
*Как мисля*: Виждам, че това е квадратно уравнение във вида ax²+bx+c=0 с a=1, b=-4, c=3. Директно прилагам Виет: сума = -b/a = 4, произведение = c/a = 3.
*Забележи*: Ако бях решил уравнението, корените са 1 и 3, сума 4, произведение 3 — съвпада.

**Пример 2 (типичен, не от минала олимпиада)**: Кубичното уравнение 2x³ - 8x² + 6x - 4 = 0 има корени p,q,r. Намери p+q+r и pqr.
*Как мисля*: Уравнението е ax³+bx²+cx+d=0 с a=2, b=-8, c=6, d=-4. Сума p+q+r = -b/a = 8/2 = 4. Произведение pqr = -d/a = -(-4)/2 = 2.
*Забележи*: Сумата на произведенията по две: pq+qr+rp = c/a = 6/2 = 3.

**Пример 3 (edge case)**: Уравнението x² + 2x + 1 = 0 има корени x₁ и x₂. Намери x₁ + x₂ и x₁x₂.
*Решение*: a=1, b=2, c=1. Сума = -b/a = -2, произведение = c/a = 1. Но тук D=0, корените са равни: x₁=x₂=-1. Сума: -1 + (-1) = -2, произведение: (-1)*(-1)=1. Работи!

**Пример 4 (OLI-2-Областен кръг-1997-10 кл, Зад. 1)**: Намери всички естествени числа a,b,c, така че корените на уравненията:

да са естествени числа.
*Решение*: Нека корените на първото са x₁,x₂, на второто x₃,x₄, на третото x₅,x₆, всички естествени. От Виет:
1. x₁ + x₂ = 2a, x₁x₂ = b
2. x₃ + x₄ = 2b, x₃x₄ = c
3. x₅ + x₆ = 2c, x₅x₆ = a

Без ограничение на общността, нека x₁=1. Тогава от първо уравнение: 1 - 2a + b = 0 ⇒ b = 2a - 1.

Ако x₃,x₄,x₅,x₆ ≥ 2, то 2b = x₃+x₄ ≤ x₃x₄ = c (от второто уравнение), и 2c = x₅+x₆ ≤ x₅x₆ = a (от третото). Значи 2b ≤ c и 2c ≤ a. Но b=2a-1, значи 2(2a-1) ≤ c и 2c ≤ a. Тогава 4(2a-1) ≤ 2c ≤ a ⇒ 8a - 4 ≤ a ⇒ 7a ≤ 4. Но a е естествено число, значи a≥1, а 7a≤4 няма решение. Противоречие. Значи някой от x₃,x₄,x₅,x₆ е 1.

Нека x₃=1. Тогава от второ уравнение: 1 - 2b + c = 0 ⇒ c = 2b - 1.

Ако x₅,x₆ ≥ 2, то 2c = x₅+x₆ ≤ x₅x₆ = a. Но c=2b-1, b=2a-1, значи c=2(2a-1)-1=4a-3. Тогава 2(4a-3) ≤ a ⇒ 8a - 6 ≤ a ⇒ 7a ≤ 6. Отново a≥1, 7a≤6 няма решение. Значи някой от x₅,x₆ е 1.

Нека x₅=1. Тогава от трето уравнение: 1 - 2c + a = 0 ⇒ a = 2c - 1.

Сега имаме:

c = 2b - 1

Събираме трите уравнения: (b - 2a + 1) + (c - 2b + 1) + (a - 2c + 1) = 0 ⇒ -a - b - c + 3 = 0 ⇒ a + b + c = 3.

### 4.3 Hard examples (2-3)
**Пример 7 (OLI-2-Областен кръг-1995-11 кл, Зад. 1)**: Нека p,q >0 и параболата y=x²-2px+q няма общи точки с абсцисната ос. Докажи, че съществуват точки A и B върху параболата с AB ∥ Ox и ∠AOB=90° тогава и само тогава, когато p² < q ≤ 1/4. Намери кога A и B са единствено определени.
*Решение*: Без общи точки с Ox ⇒ дискриминантата на x²-2px+q=0 е отрицателна: (-2p)² - 4·1·q < 0 ⇒ 4p² - 4q < 0 ⇒ q > p².

Нека A(x₁,y₀), B(x₂,y₀) са точките (тъй като AB ∥ Ox, то y-координатите са равни). Те лежат на параболата, значи y₀ = x₁² - 2p x₁ + q и y₀ = x₂² - 2p x₂ + q. Тогава x₁ и x₂ са корени на уравнението t² - 2p t + (q - y₀) = 0. (Защо? От t² - 2p t + q - y₀ = 0.)

От Виет: x₁ + x₂ = 2p, x₁ x₂ = q - y₀.

Условието ∠AOB=90° при O(0,0). Това означава, че векторите OA и OB са перпендикулярни, скаларното им произведение е 0: x₁ x₂ + y₀ y₀ = 0. (Защото OA = (x₁,y₀), OB=(x₂,y₀).)
Значи x₁ x₂ + y₀² = 0.

Но x₁ x₂ = q - y₀, значи q - y₀ + y₀² = 0 ⇒ y₀² - y₀ + q = 0.

Трябва това уравнение да има решение y₀ > q - p² (защото върхът на параболата е при x=p, y=q-p², и тъй като параболата е отворена нагоре, точките с y=y₀ > q-p² са над върха).

Дискриминантата на y₀² - y₀ + q = 0 е D=1-4q. За да има реални корени, D≥0 ⇒ q ≤ 1/4.

Корените са y₀ = [1 ± √(1-4q)] / 2.

Трябва y₀ > q - p². Но q > p², и y₀ = [1 ± √(1-4q)] / 2.

## 5. Как да разпознаеш
Сигнали, че задачата е за Виет:
1. Задачата изисква сума или произведение на корени без да ги намираш.
2. Има симетрични изрази от корените (напр. x₁² + x₂², x₁³ + x₂³).
3. Уравнението има параметър и се търси връзка между параметрите.
4. Корените се срещат в няколко уравнения (като в задача със система).
5. Геометрична задача, където корените са свързани с дължини или координати.
6. Задача с полином и връзка между коефициентите.
7. Условието включва "произведението на корените", "сбора" и т.н.
8. При полагане, новото уравнение има корени, свързани с оригиналните.

Контрапримери (кога не е Виет):
- Задачи, където трябва да намериш самите корени (напр. чрез разлагане).
- Когато имаш неравенство и трябва дискриминанта.
- Задачи с комплексни корени и търсиш модул (освен ако не използваш Виет за сума/произведение).

## 6. Чести грешки
1. **Забравяне на знака**: x₁+x₂ = -b/a, а не b/a. Особено често при отрицателни b.
   *Как да избегнеш*: Винаги проверявай с пример: x² - 3x + 2 = 0, корени 1 и 2, сума 3 = -(-3)/1.

2. **При прилагане на Виет за уравнения със старш коефициент a≠1**: Забравяш да делиш на a.
   *Пример*: За 2x² - 4x + 2 = 0, сумата е -(-4)/2 = 2, а не 4.

3. **Игнориране на условието за реални корени**: Виет важи и за комплексни, но ако задачата изисква реални корени, трябва първо D≥0.
   *Пример*: В задача с парабола без пресечни точки с Ox, корените са комплексни, но Виет пак важи.

4. **Забравяне на edge case при повтарящи се корени**: Ако D=0, пак важи, но корените са равни.

5. **Объркване на коефициентите в общия вид**: В axⁿ + bxⁿ⁻¹ + ... = 0, сумата е -b/a, а не -b.

## 7. Критерии за готовност
- **Easy**: Можеш да намериш сума/произведение на корените за квадратно/кубично уравнение за ≤3 мин (3/3 задачи).
- **Medium**: Разпознаваш приложението на Виет в 8/10 вариации; решаваш 5/6 medium задачи.
- **Hard**: Решаваш 1/2 hard задачи без подсказки за ≤45 мин.

## 8. Самооценка (Quiz)
1. **Basic**: Каква е сумата на корените на x³ - 6x² + 11x - 6 = 0? (Отговор: 6)
2. **Edge case**: Уравнението x² + 4x + k = 0 има корени x₁,x₂. Ако x₁=x₂, колко е k? (Отговор: k=4)
3. **Discrimination**: Кое от следните НЕ е сигнал за Виет: а) търси се x₁² + x₂²; б) търси се |x₁ - x₂|; в) търси се най-големия корен. (Отговор: в)
4. **Counterexample**: В решение е написано: "За x² - 5x + 6 = 0, сумата е 5". Вярно ли е? (Отговор: Да, защото -b/a = -(-5)/1=5)
5. **Transfer**: Ако корените на x² - ax + b = 0 са корените на x² - cx + d = 0, повдигнати на квадрат, намери връзка между a,b,c,d. (Отговор: Нека корените на второто са p,q. Тогава за първото: корени p²,q². Сума p²+q²=a, произведение p²q²=b. Но p+q=c, pq=d. p²+q²=(p+q)²-2pq=c²-2d=a, и b=(pq)²=d². Значи a=c²-2d, b=d².)

## 9. Върни се след 3 дни
1. Винаги запомни: за ax²+bx+c=0, сума x₁+x₂=-b/a, произведение x₁x₂=c/a.
2. Проверявай знаците и дали a≠0.
3. За кубично: x₁+x₂+x₃=-b/a, x₁x₂+x₂x₃+x₃x₁=c/a, x₁x₂x₃=-d/a.
4. Edge case: когато има двоен корен, Виет пак важи.
5. Най-честата грешка е объркване на знака пред b.
