## 1. Защо е важно

## 3. Теория

### 3.1 Интуиция — пример преди формула
Разгледай триъгълник ABC със страни AB=5, BC=6, AC=7. Лицето му е 6√6. Как стигнахме до това? Нека разцепим проблема:
- **Метод 1 (тригонометрия)**: Ако намерим sinB от косинусовата теорема: cosB = (5²+6²-7²)/(2·5·6) = 1/5 → sinB = √24/5 → S = (1/2)·5·6·√24/5 = 6√6
- **Метод 2 (Херон)**: s = (5+6+7)/2 = 9 → S = √[9(9-5)(9-6)(9-7)] = √[9·4·3·2] = √216 = 6√6
Виждаш ли ползата от Херон? Той избягва тригонометрия. Но има цена: ако страните са 10, 10, 10√2, s(s-a)(s-b)(s-c) = 15(5)(5)(15-10√2) — грозно! Тук е по-добре S = (1/2)·10·10·sin45° = 25√2.

### 3.2 Формално определение
Нека △ABC има:
- Страни a, b, c (срещуположни на A,B,C)
- Полупериметър s = (a+b+c)/2
- Радиус на вписаната окръжност r
- Радиус на описаната окръжност R
- Допирателни от върхове: x = s-a, y = s-b, z = s-c
Тогава:
1. **Основа и височина**: S = (1/2)·a·h_a
2. **Тригонометрична**: S = (1/2)·b·c·sinA
3. **Чрез R**: S = a·b·c/(4R)
4. **Чрез r**: S = s·r
5. **Херон**: S = √[s(s-a)(s-b)(s-c)]

### 3.3 Теореми с доказателства
**Теорема 1 (Херон)**: За всеки триъгълник S = √[s(s-a)(s-b)(s-c)]
*Доказателство*:
1. От S = (1/2)bc·sinA и cosA = (b²+c²-a²)/(2bc)
2. sin²A = 1 - cos²A = [1 - cosA][1 + cosA] = [1 - (b²+c²-a²)/(2bc)][1 + (b²+c²-a²)/(2bc)]
3. Заместваме: sin²A = [(2bc - b² - c² + a²)/(2bc)] · [(2bc + b² + c² - a²)/(2bc)]
4. Четем като разлики на квадрати: = [a² - (b-c)²] · [(b+c)² - a²] / (4b²c²)
5. Факторизираме: = [(a-b+c)(a+b-c)] · [(b+c-a)(b+c+a)] / (4b²c²)
6. Забелязваме, че a+b+c = 2s, a-b+c = 2(s-b), a+b-c = 2(s-c), b+c-a = 2(s-a)
7. Значи sin²A = [2(s-b) · 2(s-c) · 2(s-a) · 2s] / (4b²c²) = [16s(s-a)(s-b)(s-c)] / (4b²c²) = [4s(s-a)(s-b)(s-c)] / (b²c²)
8. Следователно sinA = [2/(bc)] · √[s(s-a)(s-b)(s-c)]
9. Сега S = (1/2)bc·sinA = (1/2)bc · [2/(bc)] · √[...] = √[s(s-a)(s-b)(s-c)] ∎

**Теорема 2**: r = S/s, R = abc/(4S)
*Доказателство за r*:
1. Нека I е център на вписаната окръжност.
2. S = S_ABI + S_BCI + S_CAI = (1/2)ar + (1/2)br + (1/2)cr = (r/2)(a+b+c) = r·s
3. Оттук r = S/s
*Доказателство за R*:
1. От синусовата теорема: a = 2R·sinA
2. S = (1/2)bc·sinA = (1/2)bc·(a/(2R)) = abc/(4R)
3. Следователно R = abc/(4S) ∎

### 3.4 Връзка с училищната математика
В училище учиш S = (1/2)·основа·височина. Това е частен случай на тригонометричната формула при ъгъл 90°. Виж пример:
- Правоъгълен △ABC (C=90°), a=3, b=4, c=5
- S = (1/2)·3·4 = 6 (училищен метод)
- По тригонометрия: S = (1/2)·3·4·sin90° = 6
- По Херон: s=6, S=√[6(6-3)(6-4)(6-5)]=√[6·3·2·1]=√36=6
Виждаш съгласуваност.

### 3.5 Множество гледни точки
**Алгебрична гледна точка**: Формулите са уравнения, свързващи страни, ъгли, R, r. Пример: Ако знаеш a,b,c, можеш да намериш S по Херон, после r=S/s, R=abc/(4S).
**Геометрична гледна точка**: Формулите отразяват връзки между елементи. Например S = pr показва, че лицето е сбор от лицата на три триъгълника от центъра I до върховете.

### 3.6 Edge cases
**Случай 1: Равностранен триъгълник**
a=b=c=1. Тогава s=1.5, S=√[1.5(0.5)(0.5)(0.5)]=√[0.1875]=√(3/16)=√3/4. Но ако опиташ S = abc/(4R) с R=a/(√3)=1/√3, получаваш S=1·1·1/(4/√3)=√3/4 — съвпада. Проблем: Ако използваш S = (1/2)ab·sinC, но не знаеш ъгъл.

**Случай 2: Правоъгълен триъгълник**
a=3,b=4,c=5. s=6, S=√[6·3·2·1]=6. Но ако забравиш, че c е хипотенуза и сложиш s-a=6-5=1 (вместо s-a=6-3=3), получаваш √[6·1·2·3]=√36=6 — пак вярно. Защо? Херон работи за всякакъв ред на страните.

**Случай 3: Изроден триъгълник**
a=2,b=3,c=5. Тогава s=5, s-a=3, s-b=2, s-c=0 → S=√[5·3·2·0]=0. Това е коректно — точките са колинеарни.

**Случай 4: Тъп ъгъл**
a=2,b=3,c=4. s=4.5, S=√[4.5(2.5)(1.5)(0.5)]=√[8.4375]=√(135/16)=3√15/4. Ако използваш S = (1/2)·2·3·sinC, но C е тъп, sinC = sin(180°-C) >0, така че няма проблем.

**Случай 5: Големи числа**
a=100, b=101, c=102. s=151.5, S=√[151.5·51.5·50.5·49.5]. Изглежда страшно, но може да се опрости: 151.5=303/2, 51.5=103/2, 50.5=101/2, 49.5=99/2 → S=√[(303·103·101·99)/(16)] = (1/4)√[303·103·101·99]. Можеш да сметнеш числено ≈ 4999.75, но в олимпиади често оставят в корен.

= pq(p+q+r) + pr(p+q+r) + qr(p+q+r) - pqr - pqr - pqr + 2pqr? Не става.
Забелязваме, че p²q + p²r + pq² + q²r + pr² + qr² + 2pqr = (p+q+r)(pq+pr+qr) - pqr, което вече имаме.

Числителят: (s-b)(s-c) + (s-a)(s-c) + (s-a)(s-b) = 3s² - 2s(a+b+c) + (ab+bc+ca) + s(a+b+c) - (a b + b c + c a) ? Не.
Разкриваме: (s² -s(c+b) + bc) + (s² -s(c+a) + ac) + (s² -s(a+b) + ab) = 3s² - 2s(a+b+c) + (ab+bc+ca)
Но a+b+c=2s, така че 3s² - 4s² + (ab+bc+ca) = -s² + ab+bc+ca
Знаменателят: (s-a)(s-b)(s-c)
Значи r_a + r_b + r_c - r = S [ (-s² + ab+bc+ca) / ((s-a)(s-b)(s-c)) - 1/s ]
Но S = √[s(s-a)(s-b)(s-c)], така че S² = s(s-a)(s-b)(s-c)
Тогава изразът: S [ (-s² + ab+bc+ca) / (S² / s) - 1/s ] = S [ s(-s² + ab+bc+ca)/S² - 1/s ]
= S [ ( -s³ + s(ab+bc+ca) ) / S² - 1/s ]
= [ -s³ + s(ab+bc+ca) ] / S - S/s
Сега S/s = r, така че имаме [ -s³ + s(ab+bc+ca) ] / S - r
Но това не води до 4R. Грешка в разсъжденията.
Правилният начин: Известно е, че r_a + r_b + r_c - r = 4R. Доказателството може да се види чрез формулите:
Имаме r_a = S/(s-a), и също r_a = 4R sin(A/2) cos(B/2) cos(C/2) и т.н., но това е сложно.
По-прост начин: Да разгледаме лицето. S = r·s, и също S = (1/2)ab sinC и т.н.
Известна идентичност: 1/r = 1/r_a + 1/r_b + 1/r_c? Не.
Всъщност, от r_a = S/(s-a) и т.н., може да се докаже, че r_a + r_b + r_c - r = (abc)/S - 4S/(a+b+c) ? Не.
Но знаем, че abc = 4R S, и s = (a+b+c)/2.
Имаме r_a + r_b + r_c - r = S [1/(s-a) + 1/(s-b) + 1/(s-c) - 1/s]
Сега 1/(s-a) + 1/(s-b) + 1/(s-c) = ∑ 1/(s-a)
И ∑ 1/(s-a) = ∑ 2/(b+c-a)
Но b+c-a = 2(s-a), така че ∑ 1/(s-a) = ∑ 1/(s-a) — тавтология.
Използваме факта, че ∑ (s-a) = 3s - (a+b+c) = 3s - 2s = s
И ∑ (s-a)(s-b) = ?
Известно е, че (s-a)(s-b) = [c² - (a-b)^2]/4, но не помага.
Стандартно доказателство: r_a + r_b + r_c - r = 4R
Доказателство: За всеки триъгълник е изпълнено r_a = 4R sin(A/2) cos(B/2) cos(C/2), r_b = 4R cos(A/2) sin(B/2) cos(C/2), r_c = 4R cos(A/2) cos(B/2) sin(C/2), r = 4R sin(A/2) sin(B/2) sin(C/2)
Тогава r_a + r_b + r_c - r = 4R [ sin(A/2)cos(B/2)cos(C/2) + cos(A/2)sin(B/2)cos(C/2) + cos(A/2)cos(B/2)sin(C/2) - sin(A/2)sin(B/2)sin(C/2) ]
Изразът в скобите е точно sin((A+B+C)/2) = sin(90°) = 1, защото A+B+C=180°.
Следователно r_a + r_b + r_c - r = 4R · 1 = 4R.
Това е доказателството. В задачата просто трябва да се цитира или да се изведе по този начин.
*Забележи*: Това е пример как формулите за лице се комбинират с тригонометрични тъждества.

## 5. Как да разпознаеш

1. Дадени три страни → Херон
2. Дадени две страни и синус на ъгъла между тях → S = (1/2)ab·sinC
3. Дадени r и s → S = r·s
4. Дадени R и произведение на страни → S = abc/(4R)
5. Задачи с r_a, r_b, r_c → използвай r_a = S/(s-a)
6. Триъгълник с описана/вписана окръжност
7. Сравнение на лица (като Пр.4) → често използваме отношението на основите при еднаква височина

## 6. Чести грешки
1. **Грешка**: Използване на S = √[s(s-a)(s-b)(s-c)] без проверка дали a,b,c образуват триъгълник.
   *Защо*: Ако a+b<c, изразът под корена е отрицателен.
   *Как да избегнеш*: Винаги проверявай неравенството на триъгълника преди сметки.

2. **Грешка**: Забравяне, че sinA е същият за S = (1/2)bc·sinA и sin(180°-A), но грешно определяне на ъгъл.
   *Защо*: Ако ъгълът е тъп, sinA >0, но косинусът е отрицателен.
   *Как да избегнеш*: Винаги си представяй триъгълника.

3. **Грешка**: Объркване на s и 2s в r = S/s.
   *Защо*: s е полупериметър, не периметър.
   *Как да избегнеш*: Запомни, че s = (a+b+c)/2.

4. **Грешка**: Използване на S = abc/(4R) при изроден триъгълник (S=0).
   *Защо*: При S=0, R е безкрайност, формулата не е дефинирана.
   *Как да избегнеш*: Проверявай дали триъгълникът е неизроден.

5. **Грешка**: Мисълта, че r = S/s важи само за остроъгълни триъгълници.
   *Защо*: Формулата е вярна за всеки триъгълник.
   *Как да избегнеш*: Докажи си я за тъпоъгълен триъгълник (напр. страни 2,3,4).

6. **Грешка**: Забравяне на единиците при изчисляване на S по Херон при големи числа.
   *Защо*: Ако страните са в cm, S е в cm².
   *Как да избегнеш*: Внимавай с мерните единици.

7. **Грешка**: Невярна прилагането на формулата S = pr за четириъгълници.
   *Защо*: Формулата е само за триъгълници.
   *Как да избегнеш*: За четириъгълници използвай други методи.

## 8. Самооценка (Quiz)
1. **Basic**: Колко е лицето на триъгълник със страни 9, 10, 17? 
   *Отговор*: 9+10=19>17, 9+17>10, 10+17>9 → да. s=(9+10+17)/2=18. S=√[18(18-9)(18-10)(18-17)]=√[18·9·8·1]=√1296=36

2. **Edge case**: Може ли да използваш Херон за триъгълник със страни 1,1,2? 
   *Отговор*: Не, защото 1+1=2 → изроден триъгълник (лицето е 0). Формулата дава √[2·1·1·0]=0, което е вярно, но не е метод за намиране на лица.

3. **Discrimination**: Дадени a=5,b=5,∠C=120°. По кой метод ще намериш S?
   *Отговор*: S = (1/2)·a·b·sinC = (1/2)·5·5·sin120° = (25/2)·(√3/2) = 25√3/4. Херон също става: c²=25+25-2·5·5·cos120°=50-50·(-0.5)=75 → c=5√3, s=(5+5+5√3)/2=5(1+√3)/2, S=√[...] — по-сложно.

4. **Counterexample**: В решение пише: "За триъгълник с a=7,b=24,c=25, r=S/s=84/28=3". Грешно ли е?
   *Отговор*: S= (1/2)·7·24=84 (правоъгълен), s=(7+24+25)/2=28, r=84/28=3 → вярно. Няма грешка. (Подвеждащ въпрос — понякога решенията са верни!)

5. **Transfer**: В окръжност с R=10 е вписан триъгълник с ъгли 30°,70°,80°. Намерете лицето му.
   *Отговор*: S = abc/(4R). Но не знам страни. От синусова теорема: a=2R·sinA=20·sin30°=10, b=20·sin70°, c=20·sin80°. Тогава S = (10·20·sin70°·20·sin80°)/(4·10) = (4000·sin70°·sin80°)/40 = 100·sin70°·sin80°. Можеш да оставиш така или да сметнеш числено.
