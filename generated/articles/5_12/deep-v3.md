## 3. Теория

### 3.1 Интуиция — пример преди формула

Да решим уравнението: 2x³ - 3x² - 3x + 2 = 0. Забележи коефициентите: 2, -3, -3, 2. Те са симетрични! Това значи, че ако α е корен, то и 1/α е корен. Проверим за x=2: 2*(8) -3*(4) -3*(2) +2 = 16-12-6+2=0 → корен е. Тогава 1/2 също трябва да е корен: 2*(1/8) -3*(1/4) -3*(1/2) +2 = 0.25 - 0.75 - 1.5 + 2 = (0.25+2) + (-0.75-1.5)=2.25-2.25=0. Да, работи! Сега знаем два корена: 2 и 1/2. Третият корен? Понеже е кубично, имаме още един. Ще разделим полинома на (x-2)(x-0.5) = x² - 2.5x + 1. Делене:

(2x³ -3x² -3x +2) : (x² - 2.5x +1) = 2x +2
- (2x³ -5x² +2x)
___________
  2x² -5x +2
- (2x² -5x +2)
___________
  0

Значи 2x+2=0 → x=-1. Забележи: -1 е реципрочно на себе си. Това е ключово!

### 3.2 Формално определение

**Дефиниция**: Полином P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀ е **реципрочен**, ако за всяко k, aₖ = aₙ₋ₖ. 

Пример за n=3: a₃ = a₀, a₂ = a₁. Нашият пример: 2x³ -3x² -3x +2 → a₃=2, a₀=2; a₂=-3, a₁=-3. Да.

**Важно**: Ако n е нечетно, то -1 винаги е корен. Защо? P(-1) = aₙ(-1)ⁿ + ... + a₀. При нечетно n, (-1)ⁿ = -1. От реципрочност: aₖ = aₙ₋ₖ. Сборът на коефициентите на симетрични членове: aₖxᵏ + aₙ₋ₖxⁿ⁻ᵏ. За x=-1: aₖ(-1)ᵏ + aₙ₋ₖ(-1)ⁿ⁻ᵏ = aₖ(-1)ᵏ + aₖ(-1)ⁿ⁻ᵏ (защото aₙ₋ₖ=aₖ). При нечетно n, n-k и k имат различна четност. Затова сборът е 0. Значи целият P(-1)=0.

### 3.3 Теореми с доказателства

**Теорема 1**: Всеки реципрочен полином от нечетна степен има корен -1.

*Доказателство*: Нека P(x) реципрочен, deg P = n нечетно. Тогава P(-1) = Σaₖ(-1)ᵏ. Разглеждаме двойките: за k=0 до n, но с оглед на симетрията, групираме членовете: (aₖxᵏ + aₙ₋ₖxⁿ⁻ᵏ). При x=-1: aₖ(-1)ᵏ + aₙ₋ₖ(-1)ⁿ⁻ᵏ = aₖ(-1)ᵏ + aₖ(-1)ⁿ⁻ᵏ (от реципрочност). Сега (-1)ⁿ⁻ᵏ = (-1)ⁿ * (-1)⁻ᵏ = (-1)ⁿ * (-1)ᵏ (защото (-1)⁻ᵏ = (-1)ᵏ). Но n нечетно → (-1)ⁿ = -1. Значи: aₖ(-1)ᵏ + aₖ * [-1 * (-1)ᵏ] = aₖ(-1)ᵏ - aₖ(-1)ᵏ = 0. Това за всяка двойка. Ако n нечетно, имаме и средния член при k=(n-1)/2, но тогава aₖxᵏ и aₙ₋ₖxⁿ⁻ᵏ са един и същ член (защото k=n-k), значи имаме само един член: aₖxᵏ с k=(n-1)/2. При x=-1: aₖ(-1)ᵏ. Но тъй като всички други двойки дават 0, целият сбор е aₖ(-1)ᵏ. Грешка? Не, защото при нечетно n, n=2m+1, тогава за k=m, членът е aₘxᵐ, и aₙ₋ₖ=aₙ₋ₘ=a_{m+1}, но от реципрочност aₘ = a_{n-m} = a_{m+1}? Не! Реципрочността казва aₖ = a_{n-k}. За k=m: aₘ = a_{n-m} = a_{(2m+1)-m} = a_{m+1}. Но m и m+1 са различни! Например при n=3 (m=1): a₁ = a_{3-1} = a₂. Да, в нашия пример a₁=a₂=-3. Но това не е същият член. При x=-1, членовете са aₘxᵐ и a_{m+1}x^{m+1}. Те не са с еднакви степени, така че не са сдвоени. Всъщност, при нечетно n, няма среден член, който да е сам. Всички членове се сдвояват по двойки (k и n-k), като k=0 до n, но когато k=n-k? Тогава 2k=n, но n нечетно → няма цяло k. Значи всички членове са сдвоени и всяка двойка дава 0 при x=-1. Следователно P(-1)=0. ∎

**Теорема 2**: За реципрочен полином с четна степен n=2m, полагането t = x + 1/x го свежда до полином от степен m.

*Доказателство*: Нека P(x) = a₀xⁿ + a₁xⁿ⁻¹ + ... + aₙ, с aₖ=aₙ₋ₖ. Да разделим на xᵐ (x≠0, но 0 не е корен, защото a₀=aₙ≠0 обикновено). Получаваме: P(x)/xᵐ = a₀xᵐ + a₁xᵐ⁻¹ + ... + aₘ + ... + a₁x¹⁻ᵐ + a₀x⁻ᵐ. Сега групираме: a₀(xᵐ + x⁻ᵐ) + a₁(xᵐ⁻¹ + x¹⁻ᵐ) + ... + aₘ. Всяко xᵏ + x⁻ᵏ може да се изрази чрез t = x + 1/x. Например: x² + 1/x² = (x + 1/x)² - 2 = t² - 2; x³ + 1/x³ = (x+1/x)³ - 3(x+1/x) = t³ - 3t и т.н. Следователно, целият израз е полином Q(t) от степен m. ∎

### 3.4 Връзка с училищната математика

В училище учиш за квадратни уравнения. Реципрочните уравнения разширяват тази идея. Например квадратното уравнение x² - 3x + 1 = 0 е реципрочно (коефициенти 1,-3,1; a₂=a₀=1, a₁=a₁=-3). Решенията са [3±√5]/2. Забележи: ако α е корен, то 1/α = [3∓√5]/2 / ([3±√5]/2 * [3∓√5]/2) — всъщност, произведението на корените е 1 (от теорема на Виет: x₁x₂ = c/a = 1/1 = 1), значи 1/α е другият корен. Това е частен случай.

### 3.5 Множество гледни точки

**Алгебрична**: Разглеждаме коефициентите и полагането. Това е стандартният подход.

**Геометрична**: В комплексната равнина, корените са симетрични спрямо единичната окръжност: ако |z|=r, то |1/z|=1/r. Но при реални коефициенти, ако z е корен, то и ar{z} е корен, така че имаме симетрия спрямо реалната ос и спрямо единичната окръжност.

### 3.6 Edge cases

- **Степен 0**: Константният полином, ако a₀ ≠ 0, не е реципрочен по дефиниция? Дефиницията изисква aₖ=aₙ₋ₖ за всички k, но при n=0, имаме само a₀, и a₀=a₀, значи всеки константен полином е реципрочен. Но той няма корени (освен ако не е нула).
- **Нулев полином**: Технически реципрочен, но неинтересен.
- **Коефициент a₀=0**: Тогава полиномът има корен 0. Но ако a₀=0, от реципрочност aₙ=a₀=0, значи полиномът е делим на x, и всъщност на x², x³ и т.н. Доколкото е реципрочен, след разделяне на xᵏ, получаваме реципрочен полином с ненулеви крайни коефициенти.
- **При полагането t=x+1/x**: Ако x=0, не може. Но x=0 не е корен, както видяхме. По-сериозно: когато |t|<2, решенията за x са комплексни. Това е нормално, но трябва да се знае.

## 4. Примери с решения

### 4.1 Easy examples

**Пример 1**: Реши уравнението x⁴ - 4x³ + 6x² - 4x + 1 = 0.

*Как мисля*: Коефициенти: 1, -4, 6, -4, 1 → реципрочен (a₀=1=a₄, a₁=-4=a₃). Степен 4, четна. Полагаме t = x + 1/x. Първо, делим на x² (x≠0): x² - 4x + 6 - 4/x + 1/x² = 0. Групираме: (x² + 1/x²) -4(x + 1/x) +6=0. Но x² + 1/x² = (x+1/x)² - 2 = t² - 2. Значи: (t² - 2) -4t +6=0 → t² -4t +4=0 → (t-2)²=0 → t=2.
Сега t=2: x + 1/x = 2 → x² -2x +1=0 → (x-1)²=0 → x=1 (двоен корен).

*Забележи*: Това е (x-1)⁴, разгънато. Реципрочно уравнение може да има кратни корени.

**Пример 2**: Реши 6x⁴ - 35x³ + 62x² - 35x + 6 = 0.

*Как мисля*: Коефициенти: 6, -35, 62, -35, 6 → реципрочен. Степен 4. Полагаме t=x+1/x. Делим на x²: 6x² -35x +62 -35/x +6/x²=0. Групираме: 6(x² + 1/x²) -35(x + 1/x) +62=0. x²+1/x²=t²-2. Значи 6(t²-2) -35t +62=0 → 6t² -12 -35t +62=0 → 6t² -35t +50=0.
Дискриминанта D=1225-1200=25. t=(35±5)/12 → t₁=40/12=10/3, t₂=30/12=5/2.

Сега:
- За t=10/3: x+1/x=10/3 → 3x² -10x +3=0 → x=(10±√(100-36))/6=(10±√64)/6=(10±8)/6 → x₁=18/6=3, x₂=2/6=1/3.
- За t=5/2: x+1/x=5/2 → 2x² -5x +2=0 → x=(5±√(25-16))/4=(5±3)/4 → x₃=8/4=2, x₄=2/4=1/2.

Корени: 3, 1/3, 2, 1/2.

*Забележи*: Всички корени са реципрочни двойки.

**Пример 5**: Реши неравенството (от областен кръг 2009, но адаптирано): За a>b>0, реши (x + a)/√(x² + a²) > (x + b)/√(x² + b²).

*Как мисля*: Функциите са реципрочни? Не директно, но може да се сведе. Забелязвам, че ако разгледам функцията f(t) = (x+t)/√(x²+t²), то неравенството е f(a) > f(b). Ще изследвам f(t).

f(t) = (x+t)/√(x²+t²). Може да се представи като cosθ, където θ е ъгъл между векторите (x,t) и (1,0)? По-добре: f(t) = [x/√(x²+t²)] + [t/√(x²+t²)] = cosφ + sinφ? Не. Забелязвам, че f(t) = sign(x) * (1 + t/x) / √(1 + (t/x)²) ако x≠0. Полагам u = t/x, ако x>0. Тогава f(t) = (1 + u)/√(1+u²). Ако x<0, подобно. Значи в зависимост от знака на x.

Но в задачата имаме параметри a,b. Реалното решение е дадено, но ще го копирам с обяснения.

**Реално решение** (от областен кръг 2009):

Ще разгледаме знаците на числителите.

**Случай 1**: x > -b. Тогава двете страни са положителни (защото x+b>0 и x+a>x+b>0). Повдигаме на квадрат:
[(x+a)² / (x²+a²)] > [(x+b)² / (x²+b²)]
Привеждам под общ знаменател:
(x+a)²(x²+b²) > (x+b)²(x²+a²)
Разкривам:
Ляво: (x²+2ax+a²)(x²+b²) = x⁴ + b²x² + 2ax³ + 2ab²x + a²x² + a²b² = x⁴ + 2ax³ + (a²+b²)x² + 2ab²x + a²b²
Дясно: (x²+2bx+b²)(x²+a²) = x⁴ + a²x² + 2bx³ + 2ba²x + b²x² + a²b² = x⁴ + 2bx³ + (a²+b²)x² + 2a²bx + a²b²

Сеги ляво - дясно >0:
[ x⁴ + 2ax³ + (a²+b²)x² + 2ab²x + a²b² ] - [ x⁴ + 2bx³ + (a²+b²)x² + 2a²bx + a²b² ] = (2a-2b)x³ + (2ab² - 2a²b)x = 2(a-b)x [ x² - ab ]
Тъй като a>b>0, a-b>0, значи 2(a-b)>0, така че неравенството е x(x² - ab) > 0.

Решения: x(x - √ab)(x + √ab) > 0. Метод на интервалите: корени 0, √ab, -√ab. Знаци: за x>√ab: (+), между 0 и √ab: (-), между -√ab и 0: (+), за x<-√ab: (-). Значи x ∈ (-√ab, 0) ∪ (√ab, ∞).

Но ние сме в случай x>-b. Тъй като a>b>0, √ab < a, но -b > -√ab? Да, защото b>0, -b<0, и (-b)² = b² > ab? Не, b² > ab? b>a? Не, a>b, значи ab > b*b = b², така че √ab > b, значи -√ab < -b. Значи в интервала x>-b, решенията са x ∈ (-b, 0) ∪ (√ab, ∞) ∩ {x>-b} = (-b,0) ∪ (√ab, ∞) (защото √ab > b >0).

**Случай 2**: -a ≤ x ≤ -b. Тогава x+a ≥0, x+b ≤0. Лявата страна: (x+a)/√(x²+a²) ≥0, дясната: (x+b)/√(x²+b²) ≤0, значи ляво > дясно винаги, освен ако дясното не е 0, но при x=-b, дясното е 0, лявото положително. Значи неравенството е изпълнено за всички x в [-a, -b].

**Случай 3**: x < -a. Тогава x+a<0, x+b<0, значи двете страни са отрицателни. Повдигаме на квадрат, но се обръща знакът на неравенството, защото и двете са отрицателни и функцията y² е намаляваща за y<0. По-точно: ако A<B<0, то A² > B². Значи тук: [(x+a)² / (x²+a²)] > [(x+b)² / (x²+b²)] — същото като в случай 1. Значи отново x(x² - ab) > 0? Но сега повдигаме на квадрат и обръщаме неравенството, така че оригиналното е еквивалентно на [(x+a)² / (x²+a²)] < [(x+b)² / (x²+b²)]? Не.

Нека A = (x+a)/√(x²+a²), B=(x+b)/√(x²+b²), A<0, B<0, и искаме A>B. Тъй като A и B са отрицателни, A>B означава |A| < |B|, тъй като например -2 > -3, но |-2|=2<3=|-3|. Значи |A| < |B|. Повдигаме на квадрат: A² < B². Значи в този случай имаме:
(x+a)²/(x²+a²) < (x+b)²/(x²+b²)
Тогава ляво - дясно <0:
2(a-b)x(x² - ab) < 0 (от по-горе). Тъй като a-b>0, значи x(x² - ab) < 0.

Решения: x(x-√ab)(x+√ab) < 0. Интервали: x<-√ab: (-), -√ab<x<0: (+), 0<x<√ab: (-), x>√ab: (+). Значи x ∈ (-∞, -√ab) ∪ (0, √ab).

Сега сме в x < -a. Тъй като a>b>0, -a < -√ab (защото a>√ab? a² > ab → a>b, да). Значи x < -a < -√ab. В този интервал, решенията са x ∈ (-∞, -a) ∩ [ (-∞, -√ab) ∪ (0, √ab) ] = (-∞, -a) (защото (-∞,-a) ⊂ (-∞, -√ab) и (0,√ab) не се пресича с x<-a).

**Окончателно**: От трите случая: (-b,0) ∪ (√ab, ∞) от случай 1, [-a,-b] от случай 2, (-∞,-a) от случай 3. Обединяваме: (-∞,-a) ∪ [-a,-b] ∪ (-b,0) ∪ (√ab, ∞) = (-∞,0) ∪ (√ab, ∞).

*Забележи*: Това е реална задача, въпреки че не е уравнение, а неравенство. Реципрочността се проявява в симетрията на функцията.

### 4.3 Hard examples

**Пример 6**: Реши системата:
{ x + y = 5
{ 1/x + 1/y = 5/6

*Как мисля*: Второто уравнение: (x+y)/(xy) = 5/6. Но x+y=5, значи 5/(xy)=5/6 → xy=6. Значи x и y са корени на t² -5t +6=0 → t=2 или 3. Решения: (2,3) и (3,2).

*Забележи*: Системата е симетрична спрямо x и y, което е вид реципрочност.

**Пример 7** [IMO Shortlist 2010, зад. A2]: Нека a, b, c са реални числа, не всички равни. Да се докаже, че уравненията:
ax² + bx + c = 0
bx² + cx + a = 0
cx² + ax + b = 0
имат най-много едно общо реално решение.

*Как мисля*: Трябва да разгледаме възможните общи корени. Да предположим, че α е общ корен на първите две: aα² + bα + c = 0 и bα² + cα + a = 0. Изваждаме ги: (aα² + bα + c) - (bα² + cα + a) =0 → (a-b)α² + (b-c)α + (c-a)=0. Това е (a-b)α² - (c-b)α + (c-a)=0. Но c-a = - (a-c), и ако допуснем a≠b, можем да разделим, но по-добре да разложим. Забелязвам, че (a-b)α² - (c-b)α + (c-a) = (a-b)α² - (c-b)α - (a-c). Сега, ако заместим, може да се види, че α=1 е корен: a-b - (c-b) - (a-c) = a-b-c+b-a+c=0. Значи α=1 е корен на разликата. Значи или α=1 е общ корен, или други корени.

Ако α=1 е корен на първото, то a+b+c=0. Също за второто: b+c+a=0, същото. Значи ако a+b+c=0, то α=1 е корен на всички три. Но тогава има общ корен. Сега, има ли друг? Да предположим, че има общ корен β ≠1. Тогава от разликата, той трябва да е корен на (a-b)t² + (b-c)t + (c-a)=0, но ние знаем, че това уравнение има корени t=1 и t=(c-a)/(a-b)? От теорема на Виет: за квадратното (a-b)t² + (b-c)t + (c-a)=0, сбор на корените: -(b-c)/(a-b) = (c-b)/(a-b), произведение: (c-a)/(a-b). Ако корените са 1 и k, то 1+k = (c-b)/(a-b), 1*k = (c-a)/(a-b).

Ако β е общ корен на първите две и β≠1, то β = k = (c-a)/(a-b). Но тогава трябва да е корен и на третото? Това е сложно. Вместо това, ако има два общи корена, то тези уравнения биха били еквивалентни, но по условие a,b,c не са всички равни. 

По-хитър подход: Да разгледаме сумата от трите уравнения: (a+b+c)(x² + x + 1) = 0. Значи или a+b+c=0, или x²+x+1=0. Ако a+b+c≠0, то x²+x+1=0, което има два комплексни корена, но ние търсим реални. Значи ако a+b+c≠0, няма реални общи корени. Ако a+b+c=0, то както видяхме, x=1 е корен на всички три. Остава да видим дали има друг общ корен. Ако x=1 е корен, можем да разделим първото уравнение на (x-1): ax²+bx+c = a(x-1)(x-c/a)? По-точно, ако a+b+c=0, то за първото: ax²+bx+c = a(x² + (b/a)x + c/a). Но b/a = -1 - c/a? От a+b+c=0, b= -a-c. Значи ax² - (a+c)x + c = a(x² - x) -c(x -1) = a x (x-1) - c (x-1) = (x-1)(a x - c). Също и другите: bx²+cx+a = (x-1)(b x - a), cx²+ax+b=(x-1)(c x - b). Значи всяко уравнение има корен x=1, и друг корен: за първото x=c/a, второ x=a/b, трето x=b/c. Тези други корени са различни освен ако a=b=c, което е изключено. Значи има точно един общ корен: x=1.

*Забележи*: Тук реципрочността е в цикличността на коефициентите.

- Ако ДА → готов си.
- Ако НЕ → преговори hard примерите.

## 5. Как да разпознаеш

1. Коефициентите са симетрични: aₖ = aₙ₋ₖ
2. Уравнение, в което ако замениш x с 1/x, получаваш същото уравнение (след умножаване с xⁿ)
3. Задачи с суми от вида xᵏ + 1/xᵏ
4. Системи, симетрични спрямо променливите
5. При наличие на параметри, коефициентите образуват симетрична редица
6. Често срещани степени: 2,3,4,6
7. При полагането t=x+1/x, уравнението се понижава
8. Ако в уравнението има xⁿ и 1, но няма други членове, или членовете са сдвоени

**Контрапримери**:
- Уравнение x³ - 2x² + x - 2 =0: коефициенти 1,-2,1,-2 → не е реципрочно, защото a₀=-2, a₃=1? a₃=1 (за x³), a₀=-2, не са равни.
- Уравнение x⁴ + x³ + x² + x + 1 =0: това е реципрочно! a₄=1=a₀, a₃=1=a₁, a₂=a₂.

## 6. Чести грешки

1. **Забравяне на корена -1 при нечетна степен**: Решаваш реципрочно уравнение от степен 3 и забравяш, че -1 е корен.
   *Как да избегнеш*: Винаги при нечетна степен провери P(-1).

2. **Неправилно полагане при четна степен**: Полагаш t=x+1/x, но забравяш да разделиш на xᵏ или не изразяваш правилно xᵏ + x⁻ᵏ.
   *Как да избегнеш*: Винаги запиши P(x)/xᵐ и групирай.

3. **Забравяне, че x=0 не е решение**: Делиш на x² без да провериш, но x=0 не е корен, защото a₀ ≠0 обикновено.

4. **Грешка при решаване на уравнението за t**: След като получиш уравнение за t, решаваш го грешно.
   *Как да избегнеш*: Проверявай дискриминантата.

5. **Неправилно връщане към x**: От t=x+1/x, получаваш квадратно, но грешно го решаваш.
   *Как да избегнеш*: Винаги запиши x² - t x + 1=0 и реши с дискриминанта.

6. **Пропускане на комплексни корени**: В някои задачи се търсят само реални, но ако не е указано, трябва да се дадат всички.

7. **Объркване при неравенства**: Както в пример 5, при повдигане на квадрат трябва да се внимава със знака.

## 7. Критерии за готовност

- **Easy**: Решаваш 3 basic задачи за ≤3 мин всяка. Пример: 3x⁴ - 10x³ + 10x - 3 = 0.
- **Medium**: Разпознаваш реципрочна структура в 8/10 вариации; решаваш 5/6 medium задачи.
- **Hard**: Решаваш 1 от 2 mixed задачи без hints за ≤45 мин. Пример: Докажи, че ако x + 1/x = 3, то x⁵ + 1/x⁵ = 123.

## 8. Самооценка

1. **Basic**: Кои от тези са реципрочни полиноми?
   a) 2x³ - 5x² - 5x + 2
   b) x⁴ - 4x³ + 6x² - 4x + 1
   c) x³ - 3x² + 3x - 1
   *Отговор*: a) да (коефициенти 2,-5,-5,2); b) да (1,-4,6,-4,1); c) не (1,-3,3,-1; a₃=1, a₀=-1? не са равни)

2. **Edge case**: Какво става при x=0 в уравнението 3x⁴ + 7x³ + 8x² + 7x + 3 = 0?
   *Отговор*: x=0 не е корен, защото P(0)=3≠0. Делим на x².

3. **Discrimination**: Кое уравнение може да се реши с полагането t=x+1/x?
   a) x⁴ + 2x³ + 3x² + 2x + 1 =0
   b) x⁴ - x³ + x² - x + 1 =0
   *Отговор*: a) да, реципрочно; b) да, също реципрочно (коефициенти 1,-1,1,-1,1; a₄=1=a₀, a₃=-1=a₁, a₂=a₂)

4. **Counterexample**: Студент е решил 2x³ + 3x² + 3x + 2 =0 така: Полага t=x+1/x, умножава по x: 2x² + 3x + 3 + 2/x =0, после умножава по x: 2x³ + 3x² + 3x + 2=0, което е същото. Къде е грешката?
   *Отговор*: Не може директно да се полага t=x+1/x, защото степента е нечетна. Трябва първо да се отстрани коренът x=-1.

5. **Transfer**: Ако x + 1/x = 4, намери x³ + 1/x³.
   *Отговор*: x² + 1/x² = (x+1/x)² - 2 = 16-2=14; x³ + 1/x³ = (x+1/x)³ - 3(x+1/x) = 64 - 3*4 = 64-12=52.

3. При четна степен n=2m, полагането t=x+1/x свежда до степен m
