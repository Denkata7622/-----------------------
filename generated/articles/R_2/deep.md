## 3. Теория

### 3.1 Интуиция — пример преди формула
**Задача:** Намерете всички x, за които |x - 3| < 5.
Как мислим: Модулът |a| е разстоянието от 0 до a на числовата ос. Значи |x-3| е разстоянието от x до 3. Търсим точки x, които са на по-малко от 5 единици от 3. Това са числата между 3-5=-2 и 3+5=8. Проверяваме: ако x=0, |0-3|=3<5 (вярно); ако x=10, |10-3|=7>5 (не). Значи отговорът е -2 < x < 8.

### 3.2 Формално определение
Дефинираме модула (абсолютна стойност) на реално число x:
|x| = 
  x, ако x ≥ 0
  -x, ако x < 0

**Важно:** |x| винаги е неотрицателно. |x| = 0 само при x=0.

### 3.3 Теореми с доказателства
**Теорема 1:** |x| ≤ a ⇔ -a ≤ x ≤ a за всяко a ≥ 0.
*Доказателство:*
(⇒) Да предположим, че |x| ≤ a.
- Ако x ≥ 0, то |x| = x ≤ a, и тъй като x ≥ 0 ≥ -a, имаме -a ≤ x ≤ a.
- Ако x < 0, то |x| = -x ≤ a ⇒ x ≥ -a (умножаваме двете страни по -1, знакът се обръща). И тъй като x < 0 ≤ a, имаме -a ≤ x ≤ a.
(⇐) Да предположим, че -a ≤ x ≤ a.
- Ако x ≥ 0, |x| = x ≤ a.
- Ако x < 0, |x| = -x. От -a ≤ x ⇒ -x ≤ a (пак умножаваме по -1). Значи |x| = -x ≤ a.

**Теорема 2:** |x| ≥ a ⇔ x ≤ -a или x ≥ a за a ≥ 0.
*Доказателство:*
(⇒) |x| ≥ a.
- Ако x ≥ 0, x ≥ a.
- Ако x < 0, -x ≥ a ⇒ x ≤ -a.
(⇐) Ако x ≥ a > 0, то |x| = x ≥ a. Ако x ≤ -a < 0, то |x| = -x ≥ -(-a) = a.

**Теорема 3:** |x·y| = |x|·|y|
*Доказателство:* Разглеждаме случаи по знаците на x и y. Например, ако x<0, y>0, то x·y < 0, значи |x·y| = -(x·y) = (-x)·y = |x|·|y|. Другите случаи аналогично.

**Теорема 4 (Неравенство на триъгълника):** |x+y| ≤ |x| + |y|
*Доказателство:* От Теорема 1, знаем че -|x| ≤ x ≤ |x| и -|y| ≤ y ≤ |y|. Събираме: -(|x|+|y|) ≤ x+y ≤ |x|+|y|. Отново от Теорема 1, това е еквивалентно на |x+y| ≤ |x|+|y|.

### 3.4 Връзка с училищната математика
В училище сте срещали модули при:
- Решаване на уравнения като |x-2|=3 → x=5 или x=-1.
- Построяване на графики: графиката на y=|x| е "V"-образна.
Сега ще използваме същите идеи, но за по-сложни изрази и неравенства.

### 3.5 Множество гледни точки
Можем да мислим за модулите по два начина:
1. **Алгебрично:** Разглеждане на случаи спрямо знака на израза под модул. Например за |x-1| + |x-2|, разглеждаме интервалите x<1, 1≤x<2, x≥2.
2. **Геометрично:** |a-b| е разстоянието между a и b на числовата ос. Например |x-3| + |x+1| е сумата от разстоянията от x до 3 и до -1. Минимумът се достига, когато x е между -1 и 3.

### 3.6 Edge cases
- **a < 0 в неравенства:** Неравенствата |x| ≤ a и |x| ≥ a се дефинират само за a ≥ 0. Ако a < 0:
  - |x| ≤ a няма решение (защото |x| ≥ 0 > a)
  - |x| ≥ a винаги е вярно (защото |x| ≥ 0 ≥ a)
- **Нули в знаменател:** Ако имаме |A|/B, трябва B ≠ 0.
- **Равни корени:** При |x-a| = |x-b|, решението винаги е x = (a+b)/2, дори когато a=b (тогава x=a е решение).
- **Специални стойности:** Винаги проверявай точките, където изразът под модул е нула.

## 5. Как да разпознаеш
Сигнали, че трябва да използваш модули:
1. Виждаш |A| в уравнението/неравенството.
2. Имаш израз, който е винаги неотрицателен и се нулира в дадена точка.
3. Задачи с "разстояние" в условието.
4. Неравенства с абсолютни стойности.
5. Уравнения от вида |A| = |B| (което е еквивалентно на A=B или A=-B).

Контрапримери (кога не е модул):
- √(x²) = |x|, но ако имаш √x² без модул, грешно е.
- |x|² = x², но ако имаш x² и искаш неотрицателна стойност, не винаги е модул.

## 6. Чести грешки
1. **Грешка:** Забравяне да се проверят интервалите при разбиване.
   *Защо:* Ученикът намира корените, но не проверява дали са в интервала.
   *Как да избегнеш:* Винаги пиши интервалите и проверявай всяко решение.

2. **Грешка:** Обръщане на знака при умножение с отрицателно число вътре в модул.
   *Пример:* Ако |x-1| = -2, някои пишат x-1=-2 или x-1=2 (грешно, модул не може да е отрицателен).
   *Как да избегнеш:* Помни, че |A| ≥ 0 винаги.

3. **Грешка:** Неправилно прилагане на |A|≤a при a<0.
   *Пример:* |x-3| ≤ -1 → някои решават -(-1) ≤ x-3 ≤ -1? Грешно.
   *Как да избегнеш:* Първо провери дали a ≥ 0.

4. **Грешка:** Забравяне на някои случаи при множествени модули.
   *Пример:* В ||x| - 2| = 1, забравя се случая |x| - 2 = -1.
   *Как да избегнеш:* Винаги |A| = b ≥0 има два случая: A=b или A=-b.

5. **Грешка:** Грешно тълкуване на |A| < |B|.
   *Пример:* |x-1| < |x-3| някои решават като (x-1)² < (x-3)², но не разглеждат интервалите и пропускат части от решението.
   *Как да избегнеш:* Използвай разбиване на интервали или геометрична интерпретация.
