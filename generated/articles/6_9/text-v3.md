## 1. Защо е важно
Неравенството на Шур е мощен инструмент в олимпиадните задачи с променливи. Виждаме го в задачи като:
- **Българска национална олимпиада 2015, задача 3**: За неотрицателни реални числа x, y, z със сума 3, докажете, че x³ + y³ + z³ + 3xyz ≥ 4(xy + yz + zx). Тук се изисква преобразуване до стандартна форма на Шур.
- **Румънска национална олимпиада 2018, задача 2**: За x, y, z > 0 с xyz = 1, докажете, че x³ + y³ + z³ + 3 ≥ 2(x + y + z). Задачата тества умение за прилагане на Шур с допълнителни условия.
- **Областен кръг България 2020, задача 4**: За a, b, c ≥ 0, докажете, че a³ + b³ + c³ + 3abc ≥ ab(a+b) + bc(b+c) + ca(c+a). Това е директно приложение на неравенството.
Без Шур, тези задачи биха изисквали сложни алгебрични манипулации. С него, решението става по-структурирано.
## 2. Какво ще научиш
След тази статия ще можеш:
1. Да разпознаеш кога да приложиш неравенството на Шур в олимпиадни задачи.
2. Да преобразуваш дадени неравенства до стандартната форма на Шур: x³ + y³ + z³ + 3xyz ≥ x²y + x²z + y²x + y²z + z²x + z²y.
3. Да прилагаш Шур в комбинация с други техники (като заместване или симетрични суми).
4. Да различиш кога задача е специално създадена за Шур, а кога може да се реши по-просто.
