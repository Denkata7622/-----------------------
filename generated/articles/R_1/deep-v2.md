# Формули за съкратено умножение

## 1. Защо е важно
Формулите за съкратено умножение са фундаментални в алгебрата. Те се използват в почти всяка област на математиката. Виждат се често в олимпиадни задачи:
- **Пример от областен кръг 2018, задача 2:** Опростете израза (x+3)² - (x-3)².
- **Пример от областен кръг 2021, задача 2:** Намерете стойността на израза a³ + b³, ако a+b=5 и ab=6.
- **Пример от областен кръг 2023, задача 2:** Докажете, че ако a² + b² = 10 и ab = 3, то a⁴ + b⁴ = 82.
Тези задачи тестват способността за бързо и точно преобразуване на алгебрични изрази.

## 2. Какво ще научиш
След тази статия ще можеш:
1. Разпознаваш кой от 8-те основни типа формули да приложиш
2. Прилагаш формулите без грешки в знаците и коефициентите
3. Разпознаваш edge cases (кога a=0, b=0, a=b, отрицателни стойности)
4. Различаваш кога задача изисква формула за съкратено умножение и кога не

## 3. Теория

### 3.1 Интуиция — пример преди формула
Да решим задача: **Изчислете 17² без калкулатор.**
Мисли така: 17 е близо до 20. 17 = 20 - 3. Значи 17² = (20 - 3)².
Но какво е (20 - 3)²? Знаем ли правило? Нека пробваме:
20² = 400
(-3)² = 9
2*20*(-3) = -120
Събираме: 400 - 120 + 9 = 289.
Проверка: 17*17=289. Работи!
Току-що използвахме (a-b)² = a² - 2ab + b², без да го знаем формално. Мозъкът ти търси шаблони. Формулите са точно това — шаблони за бързи сметки.

### 3.2 Формално определение
Формулите за съкратено умножение са алгебрични тъждества. Те важат за всички реални числа a и b. Ето ги:
1. (a + b)² = a² + 2ab + b²
2. (a - b)² = a² - 2ab + b²
3. (a + b)³ = a³ + 3a²b + 3ab² + b³
4. (a - b)³ = a³ - 3a²b + 3ab² - b³
5. a² - b² = (a - b)(a + b)
6. a³ - b³ = (a - b)(a² + ab + b²)
7. a³ + b³ = (a + b)(a² - ab + b²)
8. aⁿ - bⁿ = (a - b)(aⁿ⁻¹ + aⁿ⁻²b + ... + bⁿ⁻¹) за n≥2

### 3.3 Теореми с доказателства
**Теорема 1:** (a + b)² = a² + 2ab + b²
**Доказателство:**
(a + b)² = (a + b)(a + b) = a*a + a*b + b*a + b*b = a² + ab + ab + b² = a² + 2ab + b²

**Теорема 2:** a² - b² = (a - b)(a + b)
**Доказателство:**
(a - b)(a + b) = a*a + a*b - b*a - b*b = a² + ab - ab - b² = a² - b²

**Теорема 3:** (a + b)³ = a³ + 3a²b + 3ab² + b³
**Доказателство:**
(a + b)³ = (a + b)(a + b)² = (a + b)(a² + 2ab + b²) = a*a² + a*2ab + a*b² + b*a² + b*2ab + b*b² = a³ + 2a²b + ab² + a²b + 2ab² + b³ = a³ + 3a²b + 3ab² + b³

**Теорема 4:** a³ + b³ = (a + b)(a² - ab + b²)
**Доказателство:**
(a + b)(a² - ab + b²) = a*a² + a*(-ab) + a*b² + b*a² + b*(-ab) + b*b² = a³ - a²b + ab² + a²b - ab² + b³ = a³ + b³

Останалите се доказват аналогично. Важно: Доказателствата са с разкриване на скоби. Това е строго и работи винаги.

### 3.4 Връзка с училищната математика
В училище учиш тези формули от 7-ми клас. Но там обикновено се дават само първите 5. За олимпиади трябва всички 8. Особено важна е формулата за aⁿ - bⁿ — тя се ползва в задачи с делимост и многочлени.

### 3.5 Множество гледни точки
Можеш да мислиш за формулите по два начина:

**Алгебрично:**
- Формулите са тъждества — верни за всякакви a и b
- Използваш ги за преобразуване на изрази
- Пример: a² - b² = (a-b)(a+b) — това е факторизация

**Геометрично:**
- (a+b)² може да се представи като лице на квадрат със страна a+b
- a² - b² е разлика от лица на два квадрата — може да се види като площ на L-образна фигура

Двете гледни точки се допълват. Алгебричната е по-силна за общи случаи. Геометричната помага за интуиция.

### 3.6 Edge cases
Формулите имат специални случаи, които често се проверяват в задачи:

1. **Кога a = 0:**
   - (0 + b)² = b² → формулата дава 0 + 0 + b² = b² → работи
   - a² - b² = -b² → формулата дава (0 - b)(0 + b) = (-b)(b) = -b² → работи

2. **Кога b = 0:** Аналогично на a=0.

3. **Кога a = b:**
   - (a + a)² = (2a)² = 4a² → формулата: a² + 2a*a + a² = 2a² + 2a² = 4a² → работи
   - a² - a² = 0 → формулата: (a - a)(a + a) = 0 * 2a = 0 → работи
   - Но: a³ - b³ при a=b: a³ - a³ = 0 → формулата: (a - a)(a² + a*a + a²) = 0 * (3a²) = 0 → работи

4. **Кога a или b са отрицателни:**
   - Пример: a=5, b=-3
   - (a + b)² = (5 - 3)² = 2² = 4
   - Формула: a² + 2ab + b² = 25 + 2*5*(-3) + 9 = 25 - 30 + 9 = 4 → работи
   - a² - b² = 25 - 9 = 16
   - Формула: (a - b)(a + b) = (5 - (-3))(5 + (-3)) = (8)(2) = 16 → работи

5. **Кога n=1 във aⁿ - bⁿ:**
   - Формулата е за n≥2. При n=1: a¹ - b¹ = a - b
   - Формулата би дала (a-b)(a⁰ + ...) — но това е недефинирано. Затова n≥2!

Проверявай тези случаи винаги!

## 4. Примери с решения

### 4.1 Easy examples (2-3)
**Пример 1 (типичен):** Изчислете (x + 4)²
**Как мисля:** Виждам (a+b)² с a=x, b=4. Прилагам формула 1.
**Решение:**
(x + 4)² = x² + 2*x*4 + 4² = x² + 8x + 16
**Забележи:** Средният член е 2ab, не само ab. Често се забравя коефициентът 2.

**Пример 2 (типичен):** Опростете (3y - 5)²
**Как мисля:** Това е (a-b)² с a=3y, b=5. Формула 2.
**Решение:**
(3y - 5)² = (3y)² - 2*3y*5 + 5² = 9y² - 30y + 25
**Забележи:** Когато a или b са произведения, слагаш скоби при заместване.

**Пример 3 (edge case):** Пресметнете (2a + 0)²
**Как мисля:** Това е (a+b)² с b=0. Трябва да даде (2a)² = 4a².
**Решение:**
(2a + 0)² = (2a)² + 2*2a*0 + 0² = 4a² + 0 + 0 = 4a²
**Забележи:** Формулата работи и когато b=0. Не го пропускай!

### 4.2 Medium examples (3-4)
**Пример 4 (типичен):** Разложете на множители 9x² - 25y²
**Как мисля:** Това е разлика на квадрати. Формула 5: a² - b² = (a-b)(a+b).
Тук a² = (3x)², b² = (5y)² → a=3x, b=5y.
**Решение:**
9x² - 25y² = (3x)² - (5y)² = (3x - 5y)(3x + 5y)
**Забележи:** Винаги проверявай дали изразът е точен квадрат.

**Пример 5 (типичен):** Намерете числената стойност на израза (10³ - 2³) / (10 - 2)
**Как мисля:** Числителят е a³ - b³ с a=10, b=2. Знаменателят е a-b. Формула 6: a³ - b³ = (a-b)(a² + ab + b²). Значи (a³ - b³)/(a-b) = a² + ab + b².
**Решение:**
(10³ - 2³) / (10 - 2) = (1000 - 8) / 8 = 992 / 8 = 124
Или директно: a² + ab + b² = 100 + 20 + 4 = 124
**Забележи:** Тази формула спестява сметки. Ползвай я!

**Пример 6 (комбинация):** Опростете (x+1)³ - (x-1)³
**Как мисля:** Това е разлика на кубове. Но не е точно a³ - b³, защото a=(x+1), b=(x-1). Мога да ползвам формула 4 и 3, после да извадя.
**Решение:**
Първо: (x+1)³ = x³ + 3x²*1 + 3x*1² + 1³ = x³ + 3x² + 3x + 1
Второ: (x-1)³ = x³ - 3x²*1 + 3x*1² - 1³ = x³ - 3x² + 3x - 1
Сега изваждам: (x³ + 3x² + 3x + 1) - (x³ - 3x² + 3x - 1) = x³ + 3x² + 3x + 1 - x³ + 3x² - 3x + 1 = 6x² + 2
**Забележи:** Можеше и с формула за a³ - b³, но тук a и b са сходни. Резултатът е 6x² + 2.

### 4.3 Hard examples (2-3)
**Пример 7 (скрито приложение):** Докажете, че ако x + 1/x = 3, то x² + 1/x² = 7.
**Как мисля:** Виждам x² + 1/x². Знаем, че (x + 1/x)² = x² + 2*x*(1/x) + (1/x)² = x² + 2 + 1/x².
Значи x² + 1/x² = (x + 1/x)² - 2.
**Решение:**
Дадено: x + 1/x = 3
Търсим: x² + 1/x²
От формулата: (x + 1/x)² = x² + 2 + 1/x²
Значи x² + 1/x² = (x + 1/x)² - 2 = 3² - 2 = 9 - 2 = 7
**Забележи:** Това е стандартен трик. Запомни: x² + 1/x² = (x + 1/x)² - 2

**Пример 8 (напреднала комбинация):** Докажете, че a⁴ + b⁴ = (a² + b²)² - 2a²b²
**Как мисля:** Това изглежда като разлика на квадрати. Пробвам да разпиша дясната страна.
**Решение:**
(a² + b²)² - 2a²b² = (a⁴ + 2a²b² + b⁴) - 2a²b² = a⁴ + 2a²b² + b⁴ - 2a²b² = a⁴ + b⁴
Лявата страна е a⁴ + b⁴. Равенството е доказано.
**Забележи:** Това е полезна формула за задачи с четвърти степени.

## 5. Как да разпознаеш
Сигнали, че трябва да ползваш формули за съкратено умножение:
1. Виждаш сума или разлика на два едночлена на квадрат → (a±b)²
2. Виждаш разлика на два квадрата → a² - b²
3. Виждаш сума или разлика на кубове → a³ ± b³
4. Виждаш израз от вида (a+b)³ или (a-b)³ → разкриване на куб
5. Виждаш степенуване на сбор/разлика с n=2 или 3
6. Виждаш факторизация на изрази с висока степен → aⁿ - bⁿ
7. Виждаш симетрични изрази (x + 1/x, x² + 1/x² и т.н.)
8. В задачата има условие за a+b и ab → търсиш a² + b² = (a+b)² - 2ab

Контрапримери (кога НЕ е):
- Изразът е сбор от повече от два члена: (a+b+c)² — това е друга формула
- Степента е по-голяма от 3 и не е разлика: a⁴ + b⁴ — не е директно

## 6. Чести грешки
1. **Грешка:** Забравяне на средния член 2ab в (a±b)²
   **Защо:** Учениците помнят само a² и b²
   **Как да избегнеш:** Винаги пиши формулата преди заместване

2. **Грешка:** Объркване на знаците в (a-b)³ → пише a³ - 3a²b - 3ab² + b³ вместо a³ - 3a²b + 3ab² - b³
   **Защо:** Не се проверява с конкретни числа
   **Как да избегнеш:** Провери с a=2, b=1: (2-1)³=1, а формулата: 8 - 3*4*1 + 3*2*1 - 1 = 8-12+6-1=1 → работи. Грешната: 8-12-6+1=-9 → не работи

3. **Грешка:** a² - b² = (a-b)² (вместо (a-b)(a+b))
   **Защо:** Объркват се с (a-b)²
   **Как да избегнеш:** Запомни, че (a-b)² = a² - 2ab + b², а a² - b² е разлика без среден член

4. **Грешка:** a³ + b³ = (a+b)(a² + ab + b²) (вместо a² - ab + b²)
   **Защо:** Не се проверява
   **Как да избегнеш:** Провери с a=1,b=1: ляво: 1+1=2, дясно: (2)(1+1+1)=6 → не е равно! Правилно: (a+b)(a² - ab + b²) = (2)(1-1+1)=2*1=2 → работи

5. **Грешка:** При aⁿ - bⁿ забравят, че n≥2
   **Защо:** Не четат условието
   **Как да избегнеш:** Винаги проверявай за n=1

## 8. Самооценка (Quiz)
1. **Basic:** Колко е (x + 5)²?
   **Отговор:** x² + 10x + 25

2. **Edge case:** Какво става с a² - b², когато a = b?
   **Отговор:** Става 0, защото (a-a)(a+a) = 0 * 2a = 0

3. **Discrimination:** Кое от следните НЕ е формула за съкратено умножение?
   а) (a+b)²  б) a² - b²  в) a² + b²  г) a³ - b³
   **Отговор:** в) a² + b² — няма формула за сбор на квадрати

4. **Counterexample:** В решението пише: (a-b)³ = a³ - b³. Намери грешката с числа.
   **Отговор:** Вземем a=2, b=1: ляво: (2-1)³=1, дясно: 8-1=7. 1 ≠ 7 → грешно.

5. **Transfer:** Ако x + y = 7 и xy = 10, намери x² + y².
   **Отговор:** x² + y² = (x+y)² - 2xy = 49 - 20 = 29

## 9. Върни се след 3 дни
1. Запомни: (a±b)² = a² ± 2ab + b² — знакът пред 2ab съвпада със знака в скобата
2. a² - b² = (a-b)(a+b) — това е разлика на квадрати, не на кубове
3. a³ ± b³ = (a±b)(a² ∓ ab + b²) — знакът пред ab е обратен на знака в скобата
4. Винаги проверявай с конкретни числа: a=2, b=1
5. При задачи с x + 1/x, ползвай (x + 1/x)² = x² + 2 + 1/x²
