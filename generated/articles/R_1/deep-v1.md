# Формули за съкратено умножение

## 1. Защо е важно

Формулите за съкратено умножение са фундаментални в олимпиадната математика. Те се появяват в задачи от областни и национални кръгове. Например:
- **Задача 2018-11-2**: Докажете, че за всяко реално число x е изпълнено: x⁴ + 4 = (x² + 2x + 2)(x² - 2x + 2). Тук се използва a⁴ + 4b⁴ = (a² + 2ab + 2b²)(a² - 2ab + 2b²).
- **Задача 2021-11-2**: Намерете стойността на израза (2 + √3)³ + (2 - √3)³. Изисква прилагане на (a+b)³ + (a-b)³.
- **Задача 2023-11-2**: Докажете, че ако a + b = 5 и ab = 3, то a³ + b³ = 80. Директно приложение на a³ + b³ = (a+b)(a² - ab + b²).

Тези задачи тестват способността да видиш скритата структура и да приложиш подходящата формула.

## 2. Какво ще научиш

След тази статия ще можеш:
1. Да прилагаш основните формули: (a±b)², (a±b)³, a²-b², a³±b³, aⁿ-bⁿ без грешки.
2. Да разпознаваш кога задача изисква съкратено умножение в маскирана форма.
3. Да комбинираш няколко формули в една задача.
4. Да различиш кога задача е за съкратено умножение, а кога за други техники (напр. факторизация по други методи).

## 3. Теория

### 3.1 Интуиция — пример преди формула

Представи си, че трябва да пресметнеш 17² - 13². Можеш да сметнеш 289 - 169 = 120. Но има по-бърз начин: 17² - 13² = (17-13)(17+13) = 4 * 30 = 120. Виждаш ли? Това не е магия — има логика. Формулата a² - b² = (a-b)(a+b) винаги работи. Опитай със собствени числа: 10² - 6² = (10-6)(10+6) = 4*16=64, а 100-36=64. Работи!

### 3.2 Формално определение

Формулите за съкратено умножение са алгебрични тъждества, които опростяват изрази. Основните са:
- (a + b)² = a² + 2ab + b²
- (a - b)² = a² - 2ab + b²
- (a + b)³ = a³ + 3a²b + 3ab² + b³
- (a - b)³ = a³ - 3a²b + 3ab² - b³
- a² - b² = (a - b)(a + b)
- a³ - b³ = (a - b)(a² + ab + b²)
- a³ + b³ = (a + b)(a² - ab + b²)
- За n ≥ 2: aⁿ - bⁿ = (a - b)(aⁿ⁻¹ + aⁿ⁻²b + ... + abⁿ⁻² + bⁿ⁻¹)

Тези равенства са верни за всички реални числа a, b.

### 3.3 Теореми с доказателства

**Теорема 1:** (a + b)² = a² + 2ab + b²
*Доказателство:*
(a + b)² = (a + b)(a + b) = a*a + a*b + b*a + b*b = a² + ab + ab + b² = a² + 2ab + b². □

**Теорема 2:** a² - b² = (a - b)(a + b)
*Доказателство:*
(a - b)(a + b) = a*a + a*b - b*a - b*b = a² + ab - ab - b² = a² - b². □

**Теорема 3:** (a + b)³ = a³ + 3a²b + 3ab² + b³
*Доказателство:*
(a + b)³ = (a + b)(a + b)² = (a + b)(a² + 2ab + b²) = a*a² + a*2ab + a*b² + b*a² + b*2ab + b*b² = a³ + 2a²b + ab² + a²b + 2ab² + b³ = a³ + 3a²b + 3ab² + b³. □

**Теорема 4:** aⁿ - bⁿ = (a - b)(aⁿ⁻¹ + aⁿ⁻²b + ... + bⁿ⁻¹) за n ≥ 2
*Доказателство:*
Умножаваме (a - b) по сбора S = aⁿ⁻¹ + aⁿ⁻²b + ... + abⁿ⁻² + bⁿ⁻¹:
(a - b)S = a*S - b*S = (aⁿ + aⁿ⁻¹b + ... + a²bⁿ⁻² + abⁿ⁻¹) - (aⁿ⁻¹b + aⁿ⁻²b² + ... + abⁿ⁻¹ + bⁿ) = aⁿ + (aⁿ⁻¹b - aⁿ⁻¹b) + ... + (abⁿ⁻¹ - abⁿ⁻¹) - bⁿ = aⁿ - bⁿ. □

### 3.4 Връзка с училищната математика

В училище сте срещали тези формули, но тук ще ги използваме по-напреднал начин. Например, докато в училище решавате (x+2)² = x² + 4x + 4, в олимпиади ще видите задачи като: "Ако x + 1/x = 3, намерете x³ + 1/x³". Това изисква прилагане на (a+b)³ = a³ + b³ + 3ab(a+b) с a=x, b=1/x.

### 3.5 Множество гледни точки

Можеш да мислиш за формулите по два начина:
1. **Алгебрично**: Като разкриване на скоби и привеждане под общ вид.
2. **Геометрично**: (a+b)² може да се представи като лице на квадрат със страна a+b, разделен на четири части: квадрат a², квадрат b² и два правоъгълника ab.

Двете гледни точки се допълват. Алгебричният подход е по-общ, но геометричният дава интуиция.

### 3.6 Edge cases

Формулите имат специални случаи, които често се пропускат:
- **При a=0 или b=0**: (0+b)² = b², което съвпада с 0² + 2*0*b + b² = b². Работи.
- **При a=b**: a² - a² = 0, а (a-a)(a+a) = 0*2a = 0. Работи.
- **При n=1**: a¹ - b¹ = a - b, но формулата aⁿ-bⁿ = (a-b)(...) е дефинирана за n≥2. За n=1 не се прилага!
- **При отрицателни степени**: Формулите не са дефинирани за отрицателни n.
- **Когато a или b са изрази с променливи**: Пример: (x-1)³ при x=1 дава 0, което е коректно.

## 4. Примери с решения

### 4.1 Easy examples (2-3)

**Пример 1 (типичен, не от минала олимпиада):** Пресметнете (5 + 3)².
*Как мисля:* Това е директно приложение на (a+b)².
*Решение:* a=5, b=3 → (5+3)² = 5² + 2*5*3 + 3² = 25 + 30 + 9 = 64.
*Забележи:* Можеш да сметнеш 8²=64, но формулата е упражнение.

**Пример 2 (типичен, не от минала олимпиада):** Пресметнете 7² - 3².
*Как мисля:* Прилагам a² - b² = (a-b)(a+b).
*Решение:* a=7, b=3 → 7² - 3² = (7-3)(7+3) = 4 * 10 = 40.
*Забележи:* Проверка: 49 - 9 = 40. Работи.

**Пример 3 (типичен, не от минала олимпиада):** Пресметнете (2x - 3)² за x=1.
*Как мисля:* Това е (a-b)² с a=2x, b=3.
*Решение:* (2x - 3)² = (2x)² - 2*(2x)*3 + 3² = 4x² - 12x + 9. За x=1: 4*1 - 12*1 + 9 = 4 - 12 + 9 = 1.
*Забележи:* Директно: (2*1 - 3)² = (-1)²=1. Формулата работи.

### 4.3 Hard examples (2-3)

**Пример 7 (типичен, не от минала олимпиада):** Докажете, че ако a + b + c = 0, то a³ + b³ + c³ = 3abc.
*Как мисля:* Ще използвам, че c = -a - b, и ще заместя.
*Решение:*
От c = -a - b.
a³ + b³ + c³ = a³ + b³ + (-a-b)³ = a³ + b³ - (a³ + 3a²b + 3ab² + b³) = a³ + b³ - a³ - 3a²b - 3ab² - b³ = -3a²b - 3ab².
Сега 3abc = 3ab(-a-b) = -3a²b - 3ab².
Сравнявам: -3a²b - 3ab² = -3a²b - 3ab². Равни са.
*Забележи:* Това е важна идентичност при сума 0.

**Пример 8 (типичен, не от минала олимпиада):** Съкратете дробта (x⁴ - 16) / (x² + 4x + 4) за x ≠ -2.
*Как мисля:* Числителят е x⁴ - 16 = (x²)² - 4² = (x² - 4)(x² + 4). Знаменателят е (x+2)². Ще разложа още.
*Решение:*
x⁴ - 16 = (x² - 4)(x² + 4) = (x-2)(x+2)(x² + 4)

*Забележи:* При x=2: числител 16-16=0, знаменател 4+8+4=16, стойност 0. В отговора: (2-2)(4+4)/(2+2)=0. Работи.

Сигнали, че задачата е за съкратено умножение:
1. Виждаш сбор или разлика на квадрати или кубове: a² ± b², a³ ± b³.
2. Виждаш израз от вида (a ± b)² или (a ± b)³ в условието.

4. Задача за разлагане на множители на полином.

Контрапримери:
- Задача: Разложи a² + b². Не може с реални множители! (освен тривиално)

## 6. Чести грешки

1. **Грешка:** (a + b)² = a² + b² (без 2ab)
   *Защо:* Забравя се средният член.
   *Как да избегнеш:* Винаги си представяй (a+b)² = a² + 2ab + b² като площи.

2. **Грешка:** a³ - b³ = (a - b)(a² - ab + b²) (знакът пред ab)
   *Защо:* Обърква се с a³ + b³.
   *Как да избегнеш:* Запомни: при разлика (a - b), във втората скоба е a² + ab + b².

3. **Грешка:** Прилагане на a² - b² за a² + b².
   *Защо:* Мисли се, че a² + b² се разлага, но не може с реални коефициенти.
   *Как да избегнеш:* Знай, че a² + b² = (a + bi)(a - bi) в комплексните, но в реалните не се разлага.

4. **Грешка:** (a - b)³ = a³ - b³ - 3ab(a - b) — грешно, трябва да е a³ - 3a²b + 3ab² - b³.
   *Защо:* Объркване с алтернативната форма.
   *Как да избегнеш:* Провери с числа: a=2,b=1 → (2-1)³=1, а 8 - 1 - 3*2*1*(1) = 7 - 6 = 1? Грешно: 8 - 1 =7, 7 - 6=1, но това не е стандартната грешка. По-добре използвай основната формула.

5. **Грешка:** a⁴ - b⁴ = (a - b)(a³ + a²b + ab² + b³) (пропускат се множителите).
   *Защо:* Не се знае, че a⁴ - b⁴ = (a² - b²)(a² + b²) = (a - b)(a + b)(a² + b²).
   *Как да избегнеш:* Винаги проверявай с числа: a=2,b=0 → 16 - 0 = 16, а (2-0)(8 + 0 + 0 + 0)=2*8=16? Работи, но не е пълното разлагане. Задачата може да изисква пълно разлагане.

6. **Грешка:** При aⁿ - bⁿ за n=1, използват формулата за n≥2.
   *Защо:* Не се чете внимателно.
   *Как да избегнеш:* Формулата aⁿ - bⁿ = (a-b)(...) е валидна само за n ≥ 2. За n=1 е просто a-b.

7. **Грешка:** Забравяне на edge case при съкращаване на дроби: например, съкращаване на (x² - 4)/(x - 2) без да се посочва, че x ≠ 2.
   *Защо:* Не се включва домейна.
   *Как да избегнеш:* Винаги отбелязвай ограниченията.

## 8. Самооценка (Quiz)

1. **Basic (дали знае какво е):** Колко е (5 - 2)²?
   *Отговор:* 5² - 2*5*2 + 2² = 25 - 20 + 4 = 9. Или директно 3²=9.

2. **Edge case (знае ли кога НЕ работи):** Може ли да разложиш a² + b² с реални множители?
   *Отговор:* Не, освен тривиално (като (a)² + (b)²). В реалните числа няма неразривни множители.

3. **Discrimination (различава ли X от Y):** Коя задача е за съкратено умножение?
   а) Намери корените на x² - 5x + 6 = 0.
   б) Пресметни (7 + 4)³.
   в) Докажи, че ако a>b>0, то √a - √b < √(a-b).
   *Отговор:* б) — директно приложение.

4. **Counterexample (може ли да намери грешното в решение):** В решението: "(a+b)² = a² + b², следователно (3+4)² = 9 + 16 = 25, което е вярно, значи формулата е правилна." Къде е грешката?
   *Отговор:* (3+4)²=49, а 9+16=25 ≠ 49. Формулата (a+b)² = a² + b² е грешна. Вярно е (a+b)² = a² + 2ab + b².

5. **Transfer (може ли да приложи в нов контекст):** Ако x - y = 4 и xy = 5, намери x³ - y³.
   *Отговор:* x³ - y³ = (x-y)(x² + xy + y²) = (x-y)[(x-y)² + 3xy] = 4 * [16 + 15] = 4 * 31 = 124.

## 9. Върни се след 3 дни

1. Основните формули: (a±b)², (a±b)³, a²-b², a³±b³, aⁿ-bⁿ (n≥2).
2. Важни трикове: x² + y² = (x+y)² - 2xy, x³ + y³ = (x+y)³ - 3xy(x+y).
3. При разлика на квадрати: a² - b² = (a-b)(a+b). При разлика на кубове: a³ - b³ = (a-b)(a² + ab + b²).
4. Edge case: a² + b² не се разлага в реалните числа. За n=1 не се прилага формулата за aⁿ-bⁿ.
5. Когато видиш сбор на кубове и сумата a+b=0, използвай a³ + b³ = (a+b)(a² - ab + b²) = 0.

**Действие:** Опитай тези 3 задачи:
1. Пресметни (√5 + √3)² - (√5 - √3)².
2. Ако a + b = 10, a² + b² = 58, намери ab.
3. Разложи x⁶ - 64y⁶.
Ако решиш 2 от 3 — готов си. Ако не — върни се на Примери 5 и 6.
