## Math errors

Предложеното: 2f(1) + 1·(f(3)-f(1)) = 4·(f(3)-f(2))/1 → 2f(1) + f(3) - f(1) = 4f(3) - 4f(2) → f(1) + f(3) = 4f(3) - 4f(2) → -3f(3) + 4f(2) + f(1) = 0, което не съответства на оригиналното. → За непрекъснатост, използвай оригиналното уравнение директно: f(x+y) = [x²f(x) - y²f(y) + xy f(x-y)] / (x² - y²). При y→0, използвай ограничеността на f и факта, че f(0)=0.
