# Сума на цифри S(n)

## 1. Защо е важно

Сумата на цифрите S(n) е мощен инструмент в олимпиадните задачи. Използва се в:
- **Делимост**: n ≡ S(n) (mod 9) — ключово в задачи като Национален кръг 2019 (9-12 клас, Зад. 3) с модул 2019 и основа 4038.
- **Оценки**: S(n) ≤ 9·⌈log₁₀ n⌉ — критично за задачи с растеж на редици или горни граници.
- **Бройни системи**: Sₚ(n) в основа p има свойства, аналогични на десетичната система.

**Реални примери:**
- Национален кръг 2019 (Зад. 3): Използва пълна система от остатъци за Sₚ(n) mod m.
- Областен кръг 2017 (8 клас, Зад. 4): Търсене на n ≤ 1000 с S(n) = S(2n), използвайки модул 9.

## 3. Теория

### 3.1 Интуиция — пример преди формула

Нека n=1234. S(1234)=1+2+3+4=10. Проверка mod 9:
- 1234 ÷ 9: 9×137=1233, остатък 1.
- 10 ÷ 9: остатък 1 → съвпадат.

**Edge case n=0:** S(0)=0, 0≡0 mod 9.

### 3.2 Формално определение

**Дефиниция:** За n∈ℕ, S(n) = сума от цифрите в десетичен запис. S(0)=0.

**Свойство 1 (Модул 9):** n ≡ S(n) (mod 9).
**Свойство 2 (Оценка):** S(n) ≤ 9·⌈log₁₀(n+1)⌉ за n≥0.

### 3.3 Теореми с доказателства

**Теорема 1:** n ≡ S(n) (mod 9).
*Доказателство:*
n = aₖ·10ᵏ + ... + a₀. Тъй като 10≡1 mod 9, то 10ᵐ≡1 mod 9. Следователно n ≡ aₖ + ... + a₀ = S(n) mod 9. ∎

**Теорема 2:** S(n) ≤ 9·⌈log₁₀(n+1)⌉.
*Доказателство:*
Нека d = ⌊log₁₀ n⌋ + 1 (брой цифри). Тогава S(n) ≤ 9d. За n≥1, d = ⌊log₁₀ n⌋ + 1 ≤ ⌈log₁₀(n+1)⌉. За n=0: ⌈log₁₀1⌉=0, S(0)=0 ≤ 0? Приемаме S(0)=0 ≤ 9·1 (ако считаме 0 за 1-цифрено). ∎

### 3.4 Връзка с училищната математика

- **Делимост на 9**: n се дели на 9 ⇔ S(n) се дели на 9.
- **Логаритми**: Броят цифри d = ⌊log₁₀ n⌋ + 1.

### 3.5 Множество гледни точки

1. **Алгебрична**: n ≡ S(n) mod 9 — инварианта за модулна аритметика.
2. **Комбинаторна**: Брой числа с фиксирана сума на цифрите.
3. **Аналитична**: S(n) = O(log n) — полезно за оценки.

### 3.6 Edge cases

- **n=0**: S(0)=0.
- **n=10ᵏ**: S(n)=1 (e.g., n=100, S=1).
- **n=10ᵏ - 1**: S(n)=9k (e.g., n=999, S=27).
- **Модул 9**: Ако n≡0 mod 9, то S(n)≡0 mod 9, но S(n) не е непременно 9 (e.g., n=18, S=9).

### 4.3 Hard examples (2-3)

**Пример 7 (Национален кръг 2019, Зад. 3):** Намери всички реални a, така че за всяка безкрайна редица от различни естествени числа a₁,a₂,... с aₙ ≤ a·n, да съществуват безбройно много aₙ с S_{4038}(aₙ) ≢ 0 mod 2019.

*Решение:*
**Ключова идея:** Във всеки блок от 2019 последователни числа, сумите на цифрите в основа 4038 дават всички остатъци mod 2019, включително ≠0.

**Стъпки:**
1. a ≥ 1 (от a₁ ≥ 1).
2. Дефинираме B = {b | S_{4038}(b) ≡ 0 mod 2019}. Множеството B е безкрайно (напр. b_k = 2019k).
3. **Контрадикция за a < 2019:** Да допуснем, че съществува редица aₙ с краен брой членове с S_{4038}(aₙ) ≢ 0 mod 2019. Тогава съществува M, такова че за m ≥ M, aₘ ∉ B.
4. За фиксирано N, разглеждаме числата a_M, a_{M+1}, ..., a_{M+N}. Те са N+1 числа, различни и ∉ B.
5. От свойството на блоковете, в интервала [1, a(M+N)] има поне ⌊a(M+N)/2019⌋ числа от B. За a < 2019, при големи N, ⌊a(M+N)/2019⌋ > N+1 (тъй като a/2019 < 1, но расте линейно). Противоречие, тъй като трябва да избегнат всички числа от B в интервала.
6. **За a ≥ 2019:** Редицата b_k = k-то число в B удовлетворява b_k ≤ 2019k + 2018 ≤ a·k за k ≥ k₀ (тъй като a ≥ 2019). В тази редица само краен брой члене могат да имат S_{4038}(b_k) ≢ 0 mod 2019 (всъщност всички са ≡0). Значи a ≥ 2019 не работи.
7. **Отговор:** 1 ≤ a < 2019.

**Пример 8 (Балканска 2018, Зад. 2):** За всяка двойка естествени числа m, n, съществува k, такова че S(k·m) > S(k·n).

*Решение:*
**Ключова идея:** Избери k, така че k·m да е число с много 9-ци, докато k·n да има малка сума на цифрите.

**Стъпки:**
1. Фиксирай m. Избери k₁, така че k₁·m = 10ᵈ - 1 (число с d девятки). Тогава S(k₁·m) = 9d.
2. За k₁·n, ако S(k₁·n) < 9d, готови сме. Но ако S(k₁·n) ≥ 9d, търсим k₂ > k₁.
3. Повтаряй стъпка 1 с по-голямо d, докато S(k·n) < S(k·m). Тъй като S(k·m) расте неограничено с d, а S(k·n) расте бавно (S(k·n) = O(log k)), винаги ще съществува подходящо k. ∎

## 6. Чести грешки

1. **Забравяне на n=0:** S(0)=0.
2. **Грешна оценка:** S(n) ≤ 9 log₁₀ n (трябва ⌊log₁₀ n⌋ + 1).
3. **Модулна грешка:** За основа p, използване на mod 9 вместо mod (p-1).
4. **Пропускане на edge case:** e.g., n=10ᵏ (S=1).
5. **Неправилно прилагане в блокове:** В Пример 7, забравяне, че сумите на цифрите дават пълна система от остатъци.
