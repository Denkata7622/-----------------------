# Сума на цифри S(n)

## 1. Защо е важно

Сумата на цифрите S(n) е мощен инструмент в олимпиадните задачи. Примери:
- **Национален кръг 2019 (9-12 клас, Зад. 3)**: Задача с редици и сума на цифри в основа 4038 по модул 2019.
- **Областен кръг 2017 (8 клас, Зад. 4)**: Търсене на числа с S(n) = S(2n).
- **Балканска олимпиада 2018 (Зад. 2)**: Сравнение на S(k·m) и S(k·n).
Тези задачи използват ключови свойства: n ≡ S(n) (mod 9) и S(n) ≤ 9·⌈log₁₀ n⌉.

## 2. Какво ще научиш

След тази статия ще можеш:
1. Да прилагаш n ≡ S(n) (mod 9) за задачи с делимост.
2. Да използваш оценката S(n) ≤ 9·⌈log₁₀(n+1)⌉ за горни граници.
3. Да разпознаваш задачи със сума на цифри в различни бройни системи.
4. Да различиш кога задача е чисто за S(n) и кога е комбинирана с други техники.

## 3. Теория

### 3.1 Интуиция — пример преди формула

Нека n=1234. S(1234)=1+2+3+4=10. Проверка mod 9:
- 1234 ÷ 9: 9×137=1233, остатък 1
- 10 ÷ 9: 9×1=9, остатък 1
Съвпадат! За n=99: S(99)=18, 99≡0 mod 9, 18≡0 mod 9.

**Edge case: n=0**
S(0)=0, 0≡0 mod 9. Работи!

### 3.2 Формално определение

**Дефиниция:** За n ∈ ℕ, S(n) = сума от цифрите в десетичен запис. S(0)=0.

**Свойства:**
1. n ≡ S(n) (mod 9)
2. S(n) ≤ 9·⌈log₁₀(n+1)⌉

### 3.3 Теореми с доказателства

**Теорема 1:** n ≡ S(n) (mod 9)
*Доказателство:*
Нека n = aₖ·10ᵏ + ... + a₀. Тъй като 10≡1 (mod 9), то 10ᵐ≡1 (mod 9). Следователно:
n ≡ aₖ + ... + a₀ = S(n) (mod 9). ∎

**Теорема 2:** S(n) ≤ 9·⌈log₁₀(n+1)⌉
*Доказателство:*
Нека d = ⌊log₁₀ n⌋ + 1 (брой цифри). Тогава:
- n < 10ᵈ ⇒ d = ⌈log₁₀(n+1)⌉
- Макс. S(n) = 9d (за n=999...9)
За n=0: ⌈log₁₀1⌉=0, S(0)=0 ≤ 0? Приемаме S(0)=0 ≤ 9·1 (ако считаме 0 за 1-цифрено).

### 3.4 Връзка с училищната математика

- **Делимост на 9**: n се дели на 9 ⇔ S(n) се дели на 9.
- **Логаритми**: Брой цифри d = ⌊log₁₀ n⌋ + 1.

### 3.5 Множество гледни точки

1. **Алгебрична**: n ≡ S(n) (mod 9) — инварианта за делимост.
2. **Комбинаторна**: Брой числа с фиксирана сума на цифрите.
3. **Аналитична**: S(n) = O(log n) — растеж за редици.

### 3.6 Edge cases

- **n=0**: S(0)=0
- **n=10ᵏ**: S(n)=1 (минимум за d+1 цифри)
- **n=10ᵏ-1**: S(n)=9k (максимум за d цифри)
- **Модул 9**: Когато n≡0 (mod 9), S(n)≡0 (mod 9), но не винаги S(n)=9 (напр. n=18, S=9; n=99, S=18).

### 4.3 Hard examples (2-3)

**Пример 7:** [Национален кръг 2019, Зад. 3]
Условие: Намери всички a, така че за всяка безкрайна редица от различни естествени числа a₁,a₂,... с aₙ ≤ a·n, да има безбройно много aₙ със сума на цифри в основа 4038, неделима на 2019.

*Решение (коригирано):*
**Как мисля:** Виждам "сума на цифри в основа 4038" → S_{4038}(n). От Пример 5: n ≡ S_{4038}(n) (mod 4037). Търсим кога S_{4038}(n) ≢ 0 (mod 2019).

**Ключово наблюдение:** За числата в интервала [2019k, 2019k+2018], сумите на цифрите в основа 4038 дават всички остатъци mod 2019. Защо?
- Всяко число m = 2019k + r (0≤r≤2018)
- В основа 4038: m има същите старши цифри като 2019k, последна цифра r (тъй като r<4038)
- S_{4038}(m) = S' + r, където S' = сума на цифрите на 2019k
- ⇒ {S_{4038}(m) mod 2019} = {(c + r) mod 2019 | r=0,...,2018} = пълна система от остатъци mod 2019 (c е константа).

**Стъпка 1:** a ≥ 1 (от a₁ ≥ 1).
**Стъпка 2:** Дефинираме B = {b | S_{4038}(b) ≡ 0 mod 2019}. Множеството B е безкрайно (във всеки блок от 2019 числа има поне едно b).
**Стъпка 3:** Нека a < 2019. Да допуснем, че съществува редица aₙ, която има само краен брой членове в B. Тогава съществува M, такова че за m ≥ M, aₘ ∉ B.
**Стъпка 4:** За фиксирано N, разглеждаме числата a_M, a_{M+1}, ..., a_{M+N}. Те са N+1 числа, всяко a_{M+i} ≤ a(M+N).
**Стъпка 5:** Броят на числата в B, които са ≤ a(M+N), е поне ⌊a(M+N)/2019⌋ - C (за някаква константа C). Тъй като a<2019, за голямо N:
⌊a(M+N)/2019⌋ ≈ (a/2019)(M+N) > N+1 (тъй като a/2019 < 1, но (M+N) нараства).
Тогава броят на числата в B ∩ [1, a(M+N)] е > N+1.
**Стъпка 6:** Редицата a_M, ..., a_{M+N} има N+1 елемента, всичките извън B, но в [1, a(M+N)]. Това е невъзможно, тъй като има повече елементи в B в същия интервал. Противоречие.
**Стъпка 7:** За a ≥ 2019, контрапример: редицата b_k, където b_k = k-тото число в B (подредени). Тогава b_k ≤ 2019k + 2018 ≤ 2019(k+1) ≤ a(k+1) за a≥2019. В тази редица само краен брой членове (може би само първия) имат S_{4038}(b_k) ≢ 0 mod 2019.

**Отговор:** 1 ≤ a < 2019.

**Пример 8:** [Балканска 2018, Зад. 2]
Докажи, че за всяка естествени m,n, съществува k, такова че S(k·m) > S(k·n).

*Решение (схема):*
Избираме k, така че k·m да е число с много 9-ци. Тогава S(k·m) е голямо. За k·n, ако n не е степен на 2 или 5, k·n може да има малка сума на цифри. Пълно решение изисква теория на числата.

## 5. Как да разпознаеш

Сигнали за S(n):
1. Условието включва "сума от цифрите" или "цифрен корен".
2. Задачи с делимост на 9 или 3.
3. Задачи с растеж на редици/горни граници.
4. Бройни системи с различна основа.

Counterexamples:
- Задачи с произведение на цифри, а не сума.
- Задачи, където цифрите се разглеждат поотделно.

## 6. Чести грешки

1. **Забравяне на n=0**: S(0)=0, но понякога се пропуска.
2. **Грешна оценка**: S(n) ≤ 9 log₁₀ n (трябва S(n) ≤ 9(⌊log₁₀ n⌋ + 1)).
3. **Забравяне на основата**: n ≡ S(n) (mod 9) важи само за десетична система.
4. **Пропускане на edge case**: n=10ᵏ (S=1), n=10ᵏ-1 (S=9k).
5. **Объркване с броя цифри**: S(n) ≠ броя цифри.
