## 3. Теория

### 3.1 Интуиция — пример преди формула
Разгледай задача: Три числа образуват ГП. Първото е 2, второто е 6, третото е 18. Намери частното.
- Виждаш: 2, 6, 18 → 6/2=3, 18/6=3 → частно q=3
Сега: Ако първото е 4, третото е 1, и те образуват ГП с три члена, намери второто.
- Не е толкова очевидно! Трябва формално условие: (второ)^2 = първо * трето
- Значи b² = a*c → b²=4*1=4 → b=2 или b=-2

**Друг пример за интуиция:**
Представи си, че влак ускорява: ден 1 изминава 100 км, ден 2 - 105 км, ден 3 - 110 км. Това е АП с a₁=100, d=5. Ако ускоряването е процентно: ден 1 - 100 км, ден 2 - 110 км, ден 3 - 121 км, това е ГП с q=1.1.

### 3.2 Формално определение
- **Аритметична прогресия (АП)**: Ред от числа, където разликата между всеки два съседни е константа. Формули:
  - Общ член: aₙ = a₁ + (n−1)d
  - Сума: Sₙ = n(a₁ + aₙ)/2 = n[2a₁ + (n−1)d]/2
- **Геометрична прогресия (ГП)**: Ред от числа, където частното между всеки два съседни е константа. Формули:
  - Общ член: aₙ = a₁·qⁿ⁻¹
  - Сума (крайна): Sₙ = a₁(qⁿ - 1)/(q - 1) за q ≠ 1
  - Сума (безкрайна): S = a₁/(1 - q) само ако |q| < 1

**Пояснение за индексите:**
- За n=1: a₁ = a₁ + (1-1)d = a₁ (вярно)
- За n=2: a₂ = a₁ + d
- За n=3: a₃ = a₁ + 2d
Винаги тествай с малки n!

### 3.3 Теореми с доказателства
**Теорема 1:** За три последователни члена на ГП: b² = a·c.
- *Доказателство:* Нека членовете са a, b, c. По дефиниция: b/a = c/b → b² = a·c.

**Теорема 2:** Сумата на първите n члена на АП: Sₙ = n(a₁ + aₙ)/2.
- *Доказателство:* Запиши Sₙ = a₁ + a₂ + ... + aₙ
  Sₙ = aₙ + aₙ₋₁ + ... + a₁
  Събери двата реда: 2Sₙ = (a₁+aₙ) + (a₂+aₙ₋₁) + ... + (aₙ+a₁)
  Всеки двойка е равна на (a₁ + aₙ), и има n двойки → 2Sₙ = n(a₁ + aₙ) → Sₙ = n(a₁ + aₙ)/2

**Теорема 3:** Сумата на първите n члена на ГП: Sₙ = a₁(qⁿ - 1)/(q - 1) за q ≠ 1.
- *Доказателство:* Sₙ = a₁ + a₁q + a₁q² + ... + a₁qⁿ⁻¹
  Умножаваме двете страни по q: qSₙ = a₁q + a₁q² + ... + a₁qⁿ
  Изваждаме първото от второто: qSₙ - Sₙ = a₁qⁿ - a₁
  Sₙ(q - 1) = a₁(qⁿ - 1)
  Следователно Sₙ = a₁(qⁿ - 1)/(q - 1)

### 3.4 Връзка с училищната математика
- АП се среща в задачи за сбор на числа (напр. сбор на първите 100 естествени числа: S=100·101/2=5050)
- ГП се среща в задачи за лихви, популации, фрактали (напр. сложна лихва: ако вложиш 1000 лв при 5% годишно, след 3 години имаш 1000·1.05³)
- Често се комбинират с уравнения или неравенства (напр. в ирационални уравнения)

**Пример от учебник:** Задача за стая с правоъгълни плочки: първи ред 15 плочки, всеки следващ с 2 повече. Колко плочки общо за 10 реда? (АП с a₁=15, d=2, S₁₀=10·(2·15 + 9·2)/2=240)

### 3.5 Множество гледни точки
1. **Алгебрична**: Формулите са уравнения — решаваме ги. Например в ГП: aₙ = a₁·qⁿ⁻¹ → можем да изразим q = ⁿ⁻¹√(aₙ/a₁)
2. **Числова**: Вземи конкретни стойности! Провери с n=1,2,3. 
   - Пример: За АП с a₁=3, d=2: a₁=3, a₂=5, a₃=7 → S₃=15. По формула: 3·(3+7)/2=15 — работи!
   - За ГП: a₁=4, q=0.5: a₂=2, a₃=1, S₃=7. По формула: 4·(1-0.5³)/(1-0.5)=4·(0.875)/0.5=7 — вярно.
3. **Графична**: АП има линейна графика (точките лежат на права), ГП има експоненциална графика.

### 3.6 Edge cases
- **За АП**: 
  - Ако d=0, всички членове са равни. Формулите работят: aₙ=a₁, Sₙ=n·a₁
  - Ако n=1: S₁=a₁ (и по формула: 1·(a₁+a₁)/2=a₁)
  - Ако d е отрицателно: прогресията е намаляваща, но формулите важат (напр. a₁=10, d=-2: 10,8,6,...)
- **За ГП**:
  - Ако q=1: aₙ=a₁, Sₙ=n·a₁ (не Sₙ=a₁(qⁿ-1)/(q-1) — делиш на нула!)
  - Ако q=0: a₂=0, a₃=0,... Сумата: Sₙ=a₁ за n≥1 (защото след първия член всички са 0)
  - Ако |q|≥1: Безкрайната сума не съществува (расходяща)
  - Ако a₁=0: Всички членове са 0 за n≥1 → Sₙ=0
  - Ако q е отрицателно: прогресията редува знаци (напр. a₁=3, q=-1: 3,-3,3,-3...)

**Специален случай за ГП:** Когато q=-1, сумата Sₙ = a₁ ако n нечетно, 0 ако n четно.

## 4. Примери с решения

### 4.1 Easy examples (2-3)
**Пример 1:** В АП a₃=8, a₇=20. Намери a₁ и d.
- *Как мисля:* Използвам aₙ=a₁+(n-1)d два пъти
- *Решение:*
  a₃ = a₁ + 2d = 8  (1)
  a₇ = a₁ + 6d = 20 (2)
  Изваждам (1) от (2): (a₁+6d) - (a₁+2d) = 20-8 → 4d=12 → d=3
  От (1): a₁ + 2*3 = 8 → a₁=2
- *Забележи:* Винаги проверявам: a₃=2+2*3=8, a₇=2+6*3=20 — вярно.

**Пример 2:** В ГП b₂=6, b₄=24. Намери q.
- *Решение:* b₂=b₁·q=6, b₄=b₁·q³=24
  Дялам: (b₁·q³)/(b₁·q) = 24/6 → q²=4 → q=2 или q=-2
- *Забележи:* Две възможни прогресии! За q=2: b₁=3 → 3,6,12,24,...
  За q=-2: b₁=-3 → -3,6,-12,24,...

**Пример 3 (edge case):** Намери сумата на ГП: 5, 0, 0, 0, ... за n=10.
- *Решение:* Това е ГП с a₁=5, q=0. Сумата Sₙ=5 за всяко n≥1 (защото след първия член всички са 0)
- *Забележи:* Формулата Sₙ=a₁(qⁿ-1)/(q-1) не работи при q=0! Трябва специален случай.

### 4.2 Medium examples (3-4)
**Пример 4:** Три числа образуват ГП. Сборът им е 21, а произведението е 216. Намери числата.
- *Как мисля:* Нека членовете са a/q, a, a·q (симетрично представяне)
- *Решение:*
  (a/q) * a * (a·q) = 216 → a³=216 → a=6
  Сбор: 6/q + 6 + 6q = 21 → 6(1/q + 1 + q) = 21 → 1/q + 1 + q = 3.5
  Умножавам по q: 1 + q + q² = 3.5q → q² - 2.5q + 1=0 → 2q² - 5q + 2=0
  Корени: q=2 или q=0.5
  За q=2: числата 3,6,12
  За q=0.5: числата 12,6,3 (същите)
- *Забележи:* Винаги проверявам: 3+6+12=21, 3*6*12=216

**Пример 5:** В АП сборът на първите 10 члена е 150, а на първите 20 е 550. Намери a₁ и d.
- *Решение:*
  S₁₀ = 10a₁ + (10·9/2)d = 10a₁ + 45d = 150  (1)
  S₂₀ = 20a₁ + (20·19/2)d = 20a₁ + 190d = 550 (2)
  Умножавам (1) по 2: 20a₁ + 90d = 300 (3)
  Изваждам (3) от (2): (20a₁+190d) - (20a₁+90d) = 550-300 → 100d=250 → d=2.5
  От (1): 10a₁ + 45·2.5=150 → 10a₁ + 112.5=150 → 10a₁=37.5 → a₁=3.75
- *Забележи:* Проверка: a₁₀=3.75+9*2.5=26.25; S₁₀=10*(3.75+26.25)/2=10*30/2=150. a₂₀=3.75+19*2.5=51.25; S₂₀=20*(3.75+51.25)/2=20*55/2=550.

**Пример 6:** Безкрайна ГП: S=12, а сборът на квадратите на членовете е 48. Намери прогресията.
- *Решение:* Нека a₁=a, q=q. Тогава:
  a/(1-q)=12  (1)
  Квадратите: a², a²q², a²q⁴, ... образуват ГП с първи член a² и частно q². Сума: a²/(1-q²)=48  (2)
  От (1): a=12(1-q)
  Замествам в (2): [144(1-q)²] / (1-q²) =48
  Опростявам: 144(1-q)² / [(1-q)(1+q)] =48 → 144(1-q)/(1+q)=48
  Разделям двете страни на 48: 3(1-q)/(1+q)=1 → 3-3q=1+q → 3-1=3q+q → 2=4q → q=0.5
  От (1): a=12(1-0.5)=6
  Прогресия: 6, 3, 1.5, ...
- *Забележи:* Проверка: S=6/(1-0.5)=12. Квадрати: 36, 9, 2.25,... Сума: 36/(1-0.25)=36/0.75=48.

### 4.3 Hard examples (2-3)
**Пример 7 (реална задача):** За кои стойности на x ∈ (−π, π) числата 2^(sin x), 2 − 2^(sin x + cos x), 2^(cos x) образуват ГП?
- *Как мисля:* Три числа в ГП → квадрат на средния = произведение на крайните
- *Решение:*
  [2 - 2^(sin x + cos x)]² = 2^(sin x) · 2^(cos x)
  Дясна страна: 2^(sin x) · 2^(cos x) = 2^(sin x + cos x)
  Значи: [2 - 2^(sin x + cos x)]² = 2^(sin x + cos x)
  Въвеждам y = 2^(sin x + cos x)
  Уравнение: (2 - y)² = y → 4 - 4y + y² = y → y² - 5y + 4 = 0
  Корени: y=4 или y=1
  Случай 1: 2^(sin x + cos x) = 4 → sin x + cos x = 2
  Но sin x + cos x = √2 sin(x + π/4) ≤ √2 < 2 → няма решение
  Случай 2: 2^(sin x + cos x) = 1 → sin x + cos x = 0 → √2 sin(x + π/4) = 0 → x + π/4 = kπ → x = -π/4 + kπ
  В интервал (−π, π): за k=0: x=-π/4; k=1: x=3π/4; k=-1: x=-5π/4 < -π (не); k=2: x=7π/4 > π (не)
  Решения: x = -π/4, 3π/4
- *Забележи:* Проверка за x=-π/4:
  2^(sin x)=2^(-√2/2), 2^(cos x)=2^(√2/2), произведение=2^0=1
  Среден член: 2 - 2^(0)=2-1=1 → 1²=1 → да, ГП е.

**Пример 8 (поправен):** АП и ГП са дадени: АП: a₁, a₂, a₃; ГП: b₁, b₂, b₃. Известно е, че a₁=b₁, a₂=b₂, a₃=b₃ и a₁+a₂+a₃=21, a₁·a₂·a₃=343. Намери прогресиите.
- *Решение:* Тъй като числата са едни и същи, нека ги означим с p,q,r.
  За АП: 2q = p + r
  За ГП: q² = p·r
  Също: p+q+r=21, p·q·r=343
  От 2q=p+r и p+q+r=21 → 3q=21 → q=7
  От q²=p·r → 49=p·r
  От p+r=14
  Сега p и r са корени на t² - 14t + 49=0 → (t-7)²=0 → t=7
  Следователно p=7, r=7
  Прогресии: АП: 7,7,7 (d=0); ГП: 7,7,7 (q=1)
- *Забележи:* Това е edge case! Всички членове равни. Проверка: сбор 21, произведение 343=7³.

## 5. Как да разпознаеш
Сигнали, че задачата е за прогресии:
1. Употреба на думи като "последователни членове", "ред", "сбор на първите n"
2. Задачи с рекурентни зависимости: "всеки следващ член се получава от предходния чрез добавяне/умножение с константа"
3. Три или повече числа, за които се дава сбор и произведение (особено ако се споменава, че са в прогресия)
4. Задачи със суми, особено ако имат "n" в условието
5. Задачи с безкрайни суми (винаги ГП!)
6. Задачи, включващи повдигане на степени или логаритми (често ГП)
7. Проблеми с нарастване/намаляване с постоянна стойност или процент (АП/ГП)
8. Симетрични условия за три числа (често се представят като a/q, a, a·q за ГП)
9. Уравнения, свързани с индекси (напр. aₖ, aₖ₊₁)
10. Задачи с комбинация от аритметични и геометрични операции

Counterexamples:
- Ако имаш само две числа — не е прогресия (може да е уравнение)
- Ако зависимостта не е линейна/геометрична (напр. квадратична)
- Ако няма указание за последователност или ред

## 6. Чести грешки
1. **Грешка:** Използване на Sₙ=a₁(1-qⁿ)/(1-q) за q=1
   - *Защо:* Делиш на нула!
   - *Коригиране:* При q=1, Sₙ=n·a₁
   - *Пример:* ГП 5,5,5: S₃=15, не 5(1-1³)/(1-1) — недефинирано!

2. **Грешка:** Забравяне на двата корена при намиране на q в ГП (q и -q)
   - *Пример:* В Пример 2, ако забравиш q=-2, губиш едно решение
   - *Коригиране:* Винаги проверявай дали q може да е отрицателно

3. **Грешка:** При безкрайна ГП, използване на формулата при |q|≥1
   - *Пример:* Ако q=2, S=a₁/(1-2) = -a₁, но реално сумата клони към безкрайност
   - *Коригиране:* Проверявай |q|<1 преди да използваш S=a₁/(1-q)

4. **Грешка:** В АП, грешно индексиране: aₙ=a₁+(n-1)d, не a₁+n d
   - *Пример:* a₃=a₁+2d, не a₁+3d
   - *Коригиране:* Тествай с n=1: a₁=a₁+(1-1)d=a₁ — вярно

5. **Грешка:** В задача като Пример 7, забравяне, че sin x + cos x има максимум √2
   - *Коригиране:* Винаги проверявай диапазона на променливите

6. **Грешка:** Объркване на формули за АП и ГП (напр. използване на aₙ=a₁·qⁿ⁻¹ за АП)
   - *Коригиране:* Запомни: АП — разлика, ГП — частно

7. **Грешка:** При три числа в ГП, грешно условие: (второ)^2 = първо * трето, но само ако последователни! Ако не са последователни, не е задължително.
   - *Пример:* В ГП 2,4,8: 4²=2*8, но ако имаш 2,_,4,_,8, средното не е 4.
   - *Коригиране:* Уточнявай реда на членовете.

## 7. Критерии за готовност
- **Easy**: Реши 3 basic задачи за ≤3 мин всяка с 100% точност
- **Medium**: Разпознай техниката в 8/10 задачи; реши 5/6 medium задачи с пълни обосновки
- **Hard**: Реши 1 от 2 hard задачи без помощ за ≤45 мин с проверка на edge cases

**Конкретни задачи за тест:**
1. Easy: АП с a₄=7, a₉=22 → намери a₁, d (отг.: d=3, a₁=-2)
2. Medium: Три числа в ГП: сбор 14, произведение 64 → намери числата (отг.: 2,4,8 или 8,4,2)
3. Hard: Числата a,b,c са в АП, a²,b²,c² в ГП → намери q (отг.: 1, 3-2√2, 3+2√2)

## 8. Самооценка (Quiz)
1. **Basic**: Каква е формулата за aₙ в АП?
   - Отговор: aₙ = a₁ + (n−1)d

2. **Edge case**: Каква е сумата на ГП: 4, 0, 0, 0, ... за n=100?
   - Отговор: 4 (само първият член)

3. **Discrimination**: Кога задача е за АП, а кога за ГП? Дай по един пример.
   - Отговор: АП — линейна разлика (пример: 3,5,7,9...); ГП — постоянно частно (пример: 2,6,18,54...)

4. **Counterexample**: Намери грешката: За ГП с a₁=2, q=3, S₃=2(1-3³)/(1-3)=2(-26)/(-2)=26. Вярно ли е?
   - Отговор: Да, вярно. (Няма грешка! Това е тест за разбиране.)

5. **Transfer**: Ако числата x-1, x, x+1 образуват ГП, намери x.
   - Отговор: x²=(x-1)(x+1) → x²=x²-1 → 0=-1 → няма решение. (Освен ако не са нули, но x-1=0 и x+1=0 е невъзможно. Дори при x=0: числата -1,0,1 → (-1)·1 = -1 ≠ 0²=0, така че не е ГП.)

## 9. Върни се след 3 дни
1. Формула за aₙ в АП: aₙ=a₁+(n-1)d
2. Формула за aₙ в ГП: aₙ=a₁·qⁿ⁻¹
3. За ГП с три последователни члена: b²=ac
4. Сума на безкрайна ГП: само ако |q|<1, S=a₁/(1-q)
5. Винаги тествай edge cases: q=1, q=0, d=0, отрицателни стойности

Сега реши тези 3 задачи:
1. АП: a₃=5, a₆=14. Намери a₁ и d. [Отговор: d=3, a₁=-1]
