# Модули и неравенства с модул

Модулът $|x|$ на реално число $x$ се дефинира като $|x| = \begin{cases} x, & x \ge 0 \\ -x, & x < 0 \end{cases}$. Геометрично, той представлява разстоянието от точката $x$ до нулата на числовата ос.

**ФОРМУЛИРОВКА / КОГА СЕ ИЗПОЛЗВА**
Основните неравенства, свързани с модула, са:
1. $|x| \le a \quad \Leftrightarrow \quad -a \le x \le a$, където $a \ge 0$.
2. $|x| \ge a \quad \Leftrightarrow \quad x \le -a \ \text{ или } \ x \ge a$, където $a \ge 0$.
Те се използват за решаване на неравенства, намиране на области на дефиниция и допустими стойности, както и в доказателства, свързани с оценки.

**СВОЙСТВА**
Важни свойства са: $|x| \ge 0$, $|x|=0 \Leftrightarrow x=0$, $|xy|=|x||y|$, $|x+y| \le |x|+|y|$ (неравенство на триъгълника), $|x-y| \ge ||x|-|y||$.

**ДОКАЗАТЕЛСТВО (скица)**
Доказателството на $|x| \le a \Leftrightarrow -a \le x \le a$ следва директно от дефиницията. Ако $x \ge 0$, то $|x|=x$ и условието $x \le a$ заедно с $x \ge 0$ дава $0 \le x \le a$, което е част от $-a \le x \le a$ (тъй като $-a \le 0$). Ако $x < 0$, то $|x|=-x$ и условието $-x \le a$ е еквивалентно на $x \ge -a$. Комбинирано с $x < 0$ получаваме $-a \le x < 0$. Обединявайки двата случая, стигаме до $-a \le x \le a$. Обратната посока се проверява лесно.

**ПРИМЕР**
Решете $|2x-1| < 3$. Това е еквивалентно на $-3 < 2x-1 < 3$. Прибавяме 1: $-2 < 2x < 4$. Делим на 2: $-1 < x < 2$. Решението е интервалът $(-1, 2)$.

**ТРИК**
При неравенства от вида $|f(x)| \le g(x)$ или $|f(x)| \ge g(x)$ първо се изисква $g(x) \ge 0$, след което се разглеждат двата случая според знака на $f(x)$. Често е полезно да се интерпретира модулът като разстояние.
