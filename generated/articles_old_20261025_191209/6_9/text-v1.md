### Неравенство на Шур (класическа форма)
**ФОРМУЛИРОВКА:**  
За неотрицателни реални числа $x, y, z$ е в сила:  
$$x^3 + y^3 + z^3 + 3xyz \geq x^2y + xy^2 + y^2z + yz^2 + z^2x + zx^2,$$  
което е еквивалентно на:  
$$x^3 + y^3 + z^3 + 3xyz \geq \sum_{\text{cyc}} x^2(y + z).$$

**КОГА СЕ ИЗПОЛЗВА:**  
- В задачи с **симетрични неравенства** на три променливи.  
- Когато условието включва **сборове или произведения** (напр. $x+y+z=3$, $xyz=1$).  
- При наличие на **кубове** ($x^3, y^3, z^3$) и **смесени произведения** ($xyz$) в неравенството.  
- Често се комбинира с **AM-GM**, **Шур в други степени** или **замествания**.

**СВОЙСТВА:**  
1. **Равенство:** Достига се при $x = y = z$ или когато две променливи са равни, а третата е $0$ (напр. $x = y$, $z = 0$).  
2. **Хомогенност:** Двете страни са хомогенни от степен 3.  
3. **Връзка с други форми:** Често се представя като:  
   $$x^3 + y^3 + z^3 + 3xyz \geq xy(x + y) + yz(y + z) + zx(z + x).$$

**ДОКАЗАТЕЛСТВО (скица):**  
1. **Стандартен подход:** Преобразуваме неравенството в:  
   $$\frac{1}{2} \sum_{\text{cyc}} (x - y)^2(x + y) + xyz \geq 0.$$  
   (което е очевидно за $x, y, z \geq 0$).  
2. **Алтернативно (със заместване):** Без ограничение на общността, нека $z = \min\\{x, y, z\\}$. Заместваме $x = z + a$, $y = z + b$ ($a, b \geq 0$), разгръщаме и получаваме неотрицателен полином.  
3. **Чрез тъждество:** Използваме:  
   $$x^3 + y^3 + z^3 - 3xyz = \frac{1}{2}(x+y+z) \sum_{\text{cyc}} (x - y)^2,$$  
   и свързваме с израза в Шур.

**ПРИМЕР:**  
**Задача:** Докажете, че за $x, y, z \geq 0$ с $x + y + z = 3$ е в сила $x^3 + y^3 + z^3 + 6xyz \geq 9$.  
**Решение:**  
1. Прилагаме неравенството на Шур:  
   $$x^3 + y^3 + z^3 + 3xyz \geq \sum_{\text{cyc}} x^2(y + z).$$  
2. Преобразуваме дясната страна:  
   $$\sum_{\text{cyc}} x^2(y + z) = (x^2y + x^2z) + (y^2x + y^2z) + (z^2x + z^2y) = (x + y + z)(xy + yz + zx) - 3xyz.$$  
3. От $x + y + z = 3$:  
   $$x^3 + y^3 + z^3 + 3xyz \geq 3(xy + yz + zx) - 3xyz.$$  
4. Търсеното:  
   $$x^3 + y^3 + z^3 + 6xyz \geq 3(xy + yz + zx).$$  
5. От $(x + y + z)^2 = 9$ и AM-GM:  
   $$xy + yz + zx \leq \frac{(x + y + z)^2}{3} = 3.$$  
   Следователно $3(xy + yz + zx) \leq 9$, което води до исканото.  

**ТРИК:**  
- **Разпознавай го** при наличие на $x^3 + y^3 + z^3$ и $xyz$ в симетрично неравенство.  
- **Комбинирай го** с AM-GM или условия за сбор/произведение, за да оцениш останалите членове (напр. $xy + yz + zx$).
